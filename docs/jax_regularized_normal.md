# 正则化法向延拓、接缝控制及 Poisson 接入

实现 `packages/models/src/bspf_models/elliptic/regularized_normal.py`，驱动
`examples/pde/regularized_normal_poisson.py`。这是已有局部多项式基线的后续实验，
不是完整 Fourier continuation / FC-Gram 实现，也没有平滑归零到背景盒边界。

## 一维正则化

每根解析 B-spline 法线内侧 [-w,0] 取25个 Chebyshev–Lobatto 样本，
w=0.01。过采样拟合14次 Chebyshev 系数，再截断高阶系数：保留0…6次
用于当前 PDE 实验，同时验证0…8、0…14次控制。这是**谱截断正则化**，
不是 Tikhonov，也不是把拟合矩阵的小奇异值任意删掉。

令输入值为 v，拟合伪逆为 P，低模态投影为 Q，外侧求值矩阵为 V，则
E=VQP，外侧值为 Ev。该操作线性，内侧含边界端点，没有用真实导数。
导数诊断使用同一多项式解析求导后除以 w、w²，噪声种子90210。

## 接缝控制

不再拼接每个样条段独立拟合的切向多项式。将所有延拓样本约束统一写在
同一矩形 BSPF 场 u=Bc 上。几何样条接点不再是数值场的拼接点；物理
梯度和 Laplacian 直接由原有 BSPF 基函数计算。

这是更换表示来控制接缝，而非给旧分段场加入拉格朗日乘子或宣称提高了
三次几何样条的光滑阶数。有限空间投影仍可能产生误差，因此独立记录
全局投影后的外侧值/梯度/Laplacian，以及接缝两侧 t=k±1e-10 的差。

独立投影诊断可以使用已知 MMS 的内侧值。PDE 求解不使用该诊断系数，
也不使用真实域内解或外域数据。

## 未知场 Poisson 系统

在法线外侧 r/w=0.15、0.30、0.45 构造矩阵

    C = B_out − E B_in.

所有内侧值 B_in c 同样是未知量。令 N_e 为外侧样本数，求

    min_c ||sqrt(WΩ)((−ΔB)c−f)||²
        + ||sqrt(WΓ)(BΓ c−g)||²
        + beta²/N_e ||C c||².

延拓关系为软约束；beta=0 为同采样、同空间控制，beta=10³、10⁵用于
检查强度敏感性。beta 的数值依赖这里的归一化，没有普遍通用意义。
列缩放后截断SVD阈值1e-14。使用原有 BSPF 基函数与解析微分，整个非矩形
系统当前通过稠密最小二乘求解，**并非直接调用矩形 Poisson 逆即可完成**。

复用 N=49、背景盒[-1.2,1.2]²、齐次 Dirichlet 辅助空间、Chebyshev端点
M=P=12。物理边界每段12点；体积分阶16；法向约束每段4根法线。
低密度物理边界初轮会漏掉边界振荡，最终统一加密为每段12点。

MMS最高波数12π、种子20260918；域内独立101×103错位点，外侧独立
每段17根法线及r/w=0.113、0.287、0.479。测试范数为独立样本相对二范数。
接缝差为绝对最大分量差，包含微小位置差异，不是严格数学跳量。

## 实测结果

凸域中加入标准差1e-12的独立内侧样本扰动，局部一维延拓相对误差：

|保留次数|值|一阶法向导数|二阶法向导数|
|---|---:|---:|---:|
|14（不截断）|6.50e-6|1.55e-3|8.41e-2|
|8|2.57e-9|3.50e-7|1.02e-5|
|6|2.46e-9|2.98e-7|7.54e-6|

6次截断有偏差，但对小输入扰动更稳健。它并不消除所有外推病态性。
全局投影后外侧误差（无噪声）为凸域值1.11e-6、梯度2.82e-5、
Laplacian 2.18e-4；非星形域2.65e-7、8.51e-6、9.73e-5。
加入1e-12输入扰动后这些数字仅有轻微变化。相比局部一维值外推，
当前全局 BSPF 投影精度有限，不能宣称整个延拓已达到1e-12。

接缝附近的 Laplacian 最大绝对差从旧分段表示的凸域4.38e-5、
非星形4.54e-4，降到共享表示的9.14e-7、9.54e-7。这些差值包含
t=k±1e-10对应位置的真实变化；共享场没有样条参数接点处的独立拼接自由度。

Poisson 独立点结果如下；“PDE残差”为 ||−Δu−f||/||f||，
MMS情况下也等于 Laplacian 相对误差。

|区域|beta|解相对误差|梯度相对误差|PDE残差|
|---|---:|---:|---:|---:|
|凸域|0|7.25e-6|4.36e-5|1.81e-6|
|凸域|1e3|8.45e-6|4.99e-5|1.84e-6|
|凸域|1e5|4.78e-6|2.84e-5|1.70e-6|
|非星形|0|4.71e-6|3.66e-5|1.06e-6|
|非星形|1e3|4.70e-6|3.65e-5|1.10e-6|
|非星形|1e5|3.97e-6|2.97e-5|5.58e-6|

较强约束改善了这两个例子的解误差，但非星形域 PDE 残差增大约5倍。
这是约束偏差与物理残差的权衡，不是所有指标一致改善；本轮也没有
网格收敛或通用beta选择证明。beta=0与先前控制数值略有差异，当前
矩阵包含零约束行，稠密截断SVD在近秩亏区域对舍入敏感。

## 复现

先按 `docs/jax_bspf_smooth_extension.md` 生成可信本地 N=49几何缓存，再运行：

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python examples/pde/regularized_normal_poisson.py
MPLCONFIGDIR=/tmp/bspf-mpl python examples/pde/render_regularized_normal.py
python -m pytest -q packages/models/tests/test_regularized_normal.py packages/models/tests/test_normal_continuation.py
```

输出 `build/regularized_normal/results.json`、各beta系数/独立点NPZ、图。
法向矩阵缓存固定为当前 N=49、w=.01、保留6次、每段4根法线配置；改变
这些配置时应删除对应 `_collar.pkl` 后重建。仅加载可信本地 pickle。
测试覆盖低模态再现、误差放大下降、未知场线性关系及几何导数，4项通过。
