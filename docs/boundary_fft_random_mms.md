# 解析椭圆上的高波数随机波 Poisson MMS

## 测试定义

椭圆半轴为 (0.9, 0.76)，保持解析几何不变。使用既有 RandomWaveMMS：

```
u*(x) = sum_j a_j cos(k_j dot x + phi_j)
f(x)  = sum_j |k_j|^2 a_j cos(k_j dot x + phi_j)
g     = u* restricted to Gamma
```

固定随机种子 20260918，每个信号 8 个对数波数壳、每壳 8 个方向，共 64 个随机平面波。
波数下界 pi，上界分别 8*pi、32*pi、64*pi、128*pi，壳方差使用 k^(-5/3) 包络。
这是具有合成湍流谱包络的标量信号，不是湍流动力学模拟。

测试 M=32 至 1536，共 31 个边界分辨率。每个波数信号在整个 M 扫描中保持不变。
M 是边界未知量数，不是二维内部网格分辨率，也不包含源项参考计算的分辨率。

## 非零源项的独立处理

不能直接以 u* 为特解再检查边界修正，否则 h=g-u*|Gamma=0，边界求解器没有受到测试。
本实验计算自由空间体积势 v=integral_Omega G f，随后求解 h=g-v|Gamma。

体积势采用针对解析源项的参考算法：从 f 的每个 Fourier 模态系数除以 |k|^2 得到
一个解析特解 p。由 Green 恒等式，

```
v(x) = p(x) + D[p](x) - S[dn p](x),             x in Omega,
v|Gamma = p/2 + K[p] - S[dn p].
```

因此尽管此测试中 p 恰与 MMS 相等，最终送给边界求解器的特解是 v 而不是 p。
v 只取决于源项：给 p 添加任意调和函数不会改变 v，此性质有单独测试。
源项与边界数据因此没有被人为设成零修正；实测 ||h||/||g|| 在 1.29 至 4.21 之间。

参考算法在椭圆偏心角 phi 上使用均匀求积，与被测求解器的等弧长离散独立。
令 x(theta)=(a cos(theta),b sin(theta))，

```
d(theta+phi) = a^2 sin^2((theta+phi)/2) + b^2 cos^2((theta+phi)/2),
R(theta,phi) = -log(sqrt(d)/r0)/(2*pi),
K(theta,phi) ds_phi = -a*b/(4*pi*d) dphi.
```

对数奇异卷积的非零模态乘子为 1/(2|k|)，规则部分以 Hankel 卷积计算。
自由空间体积势参考计算使用固定 4096 点，并以 2048 点结果交叉检查；边界差异最大
1.22e-14，内部差异最大 6.11e-15，均以 MMS 解的离散 L2 范数归一化。

这不是任意 f 的通用体积奇异求积模块，也不是对整体算法总复杂度的基准测试。
结论针对源项势已独立算准时，边界 FFT 求解部分在非零源项 Poisson 问题中的收敛性。

## 独立验证

- 边界：固定 4096 个等弧长点，偏移 0.371 个步长，与训练点错开。
- 内部：固定笛卡尔点集，共 2289 点，椭圆归一化半径不超过 0.92。
- 内部单层势求值：至少 4096 个边界源点，或 4M，以避免普通求积误差污染收敛曲线。
- 相对误差为独立点上的离散 L2 误差；内部没有宣称是连续 L2 积分，也不涵盖任意贴边点。
- 高波数波动本身由源项计算表示；内部验证网格是误差采样网格，不是求解自由度网格。

最高波数上界 128*pi 的结果：

| M | 独立边界相对误差 | 内部相对误差 |
|---:|---:|---:|
| 512 | 3.918e-2 | 1.678e-11 |
| 576 | 9.307e-3 | 2.628e-14 |
| 608 | 4.826e-4 | 2.309e-15 |
| 640 | 3.873e-6 | 2.289e-15 |
| 672 | 7.476e-9 | 2.115e-15 |
| 704 | 4.259e-12 | 2.120e-15 |
| 768 | 1.814e-13 | 2.201e-15 |
| 1024 | 3.310e-14 | 2.710e-15 |

所有 124 个求解均为 6 次 GMRES 迭代。边界误差达到精度平台后不再单调下降。
内部误差更早下降是因为高频调和边界误差向内衰减；不能只用内部误差判断边界已解析。
在边界误差 1e-11 至 1e-3 的下降段，对 log10(error) 与 M 作局部线性拟合，R^2
分别为 0.9990、0.9987、0.9963、0.9945；每段只有 3 至 4 个采样点，作为曲线诊断，
不是严格渐近收敛率证明。结果支持“欠分辨阶段后进入指数/谱收敛，最终受数值精度限制”。
