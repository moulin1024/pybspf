# 二维海气模型：空间与时间分辨率审计

本次保持默认物理参数、初始条件、边界条件和 MRI-GARK4 方法不变。
验证对象是原演示的 24 小时调整过程，取 6、12、24 小时状态；尚未加入稳定度反馈。
它不能证明长期平衡态、未来锋面或新增物理也已解析充分。

## 两组独立实验

- 空间：n=33、49、65、81，统一慢宏步 H=150 s、实际快步 h=30 s。
- 时间：分别在 n=33 和 n=81 固定网格，采用 H=600、300、150 s，h=H/5。
- 所有运行均用一小时输出分组；它只组织相同的 MRI 宏步，不改变离散方法。
- 所有网格使用同一套每子区间 32 点 Gauss 积分，合计每方向 608 点。
  在这个共同物理网格上重建连续近似，不在动画像素之间做插值。
- 记录温湿度的基函数解析导数除以物理域长 L，单位为 K/m 和 (kg/kg)/m。
- 界面应力、显热、蒸发及总热通量均从各自的速度和温湿度直接调用 `bulk_flux`。
  不用低阶输出插值，也不以离散投影后的载荷替代物理通量。

## 量与误差定义

对相邻网格的物理场 a,b，定义加权 RMS 差

\[
\delta_2=\sqrt{\sum_{ij}w_{ij}|a_{ij}-b_{ij}|^2},\qquad
\delta_\infty=\max_{ij}|a_{ij}-b_{ij}|.
\]

矢量采用欧氏模长。相对量除以较细网格的 RMS 或峰值。
温度的参考尺度使用去掉空间均值的温度异常，避免除以约 290 K 而掩盖误差；
差值本身仍包含空间均值误差，不会把热量漂移减掉。
梯度、速度、流函数和通量使用本身的 RMS/峰值。报告还保存平均通量差。

这些都是有限加密差，不是相对精确解的已知误差；n=81 也不是“真解”。
空间 n 的比例不同，不从相邻差直接套 log2 计算空间阶。
时间固定按二倍加密，可以计算 p=log2(delta(H,H/2)/delta(H/2,H/4))，
但接近舍入误差或非光滑区的 p 不作为四阶证明。
原四阶方法另有代数阶条件与光滑算例验证，见 [四阶耦合说明](air_sea_mri4.md)。

## 预先设定的筛查门槛

每个输出时间、每个物理量独立检查：

1. 最细相邻网格 65/81 的相对 RMS 差 < 1%。
2. 最大差 / n=81 参考峰值 < 5%。
3. 65/81 的绝对 RMS 差小于 49/65 的差。
4. n=81 的时间差 delta(H=300,H=150) < 最细空间差的 10%。

时间差的比较不除以假设的 15，因此不依赖预设四阶来压低时间误差估计。
门槛是本次工程筛查标准，不是数学误差上界。数值低于浮点噪声时不应机械解释比值。
通过细网格筛查也不意味着最初 n=33 已通过；原网格的适用性还需看 33/49 差。

## 运行和产物

```sh
OPENBLAS_NUM_THREADS=1 MPLCONFIGDIR=/tmp/bspf-mpl \
  python examples/pde/validate_air_sea_resolution.py
OPENBLAS_NUM_THREADS=1 MPLCONFIGDIR=/tmp/bspf-mpl \
  python examples/pde/plot_air_sea_resolution.py
```

目录 `build/air_sea_resolution/` 保存每个运行的三个系数快照、步长、热水收支、耗时和
源文件指纹；指纹一致时可复用已完成运行，避免重算。若源文件改变，请使用新的 `--out`。
最终 `resolution.json` 包含所有量的空间差、时间差和逐量筛查结果。
`resolution.png` 对比各时间的空间差与最终时刻的时间差；
`fields_24h.png` 展示最细运行的环流、梯度和通量。

评估时优先查看海洋速度/流函数、三个标量梯度，以及应力和总热通量。
全域平均热水收支通过，只证明预算一致，不能替代锋面分辨率验证。

## 2026-09-19 实测结果

八组 24 小时运行全部完成。最细相邻网格 65/81 在 6、12、24 小时的 14 项指标
全部通过上述筛查。原先 33 网格未全面通过：33/49 的海洋流速 RMS 差在三个时刻分别为
5.5506%、3.3419%、1.3915%；6 小时的湿度梯度差为 1.1280%。

24 小时的结果如下，均为百分比：

| 物理量 | 33/49 相对 RMS 差 | 65/81 相对 RMS 差 | 65/81 最大差 / 参考峰值 |
| --- | ---: | ---: | ---: |
| 海洋速度 | 1.3915 | 0.1325 | 0.2157 |
| 海洋流函数 | 0.1776 | 0.00833 | 0.01786 |
| SST 梯度 | 0.2030 | 0.03858 | 0.09628 |
| 大气温度梯度 | 0.3109 | 0.05324 | 0.08052 |
| 比湿梯度 | 0.7490 | 0.1258 | 0.1805 |
| 应力矢量 | 0.00285 | 0.000167 | 0.000413 |
| 向上总热通量 | 0.01324 | 0.001187 | 0.001665 |

最难解析的是早期海洋速度：6 小时的 65/81 RMS 差为 0.9521%，接近 1% 门槛，
因此不应声称还有很大的精度余量。湿度梯度在该时刻为 0.1910%。
大尺度环流形态的流函数比局地速度更早收敛，不能仅凭双环流图像看起来一致就判断足够。

固定 n=81 时，24 小时的 H=300/150 s RMS 差：海洋速度 2.36e-15 m/s、
SST 2.70e-14 K、气温 6.27e-14 K、总热通量 1.64e-12 W/m²。
这些差已接近浮点/重建噪声；它们支持本次误差主要来自空间，而不支持据此再拟合一个
精确时间阶。新增稳定度闭合后应重新检查，因为物理响应及光滑性可能改变。

所有运行及检查时刻的最大热量预算残差为 3.96e-7 J/m²，水分残差为
5.11e-14 kg/m²。预算未经步末修补。

后续精细实验建议采用 n=81、quadrature_order=32、H=300 s、快步 60 s；
空间验证基线仍保留更细的 H=150 s、快步 30 s。
本次证明的是当前参数下这些有限加密指标通过筛查，尚未做独立积分阶数加密，
也没有证明连续 PDE 精确误差上界、长期平衡态或更强锋面的分辨率。
