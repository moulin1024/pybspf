# 精确三次 B-spline 上的分片高阶 Poisson 边界求解器

实现：`jax/src/bspf_jax/panel_poisson.py`。
实验：`examples/pde/panel_poisson_convergence.py`。

## 几何与密度分离

保留原有 `SplineDomain` 的周期三次 B-spline，不移动控制点、不重新拟合、不折线化。
初始计算片段与整数样条节点对齐；细分仅增加参数断点，不改变曲线。
当前验证对象是原有凸闭合曲线，假设曲线正则、简单且逆时针定向。
强凹陷曲线的非相邻片段近奇异作用尚未作专门验证。

设 G(x,y)=-log(|x-y|/r0)/(2*pi)，r0=L/(2*pi)。求解调和修正

```
w(x) = c + integral_Gamma G(x,y) mu(y) ds_y,
S mu + c = h,       integral_Gamma mu ds = 0.
```

实际未知量为参数密度 rho(t)=mu(gamma(t))*|gamma'(t)|，每片在 p 个 Gauss 节点上
插值为 p-1 次多项式。API 的 `order=12` 表示每片 12 个节点，即 11 次密度近似，
与几何的三次无关。不同片段不强加高阶连续性。

## 对数奇异求积

同一片段内，对精确三次几何使用

```
(gamma(t)-gamma(tau))/(t-tau)
  = gamma'(tau) + (t-tau)*gamma''(tau)/2
    + (t-tau)^2*gamma'''(panel_midpoint)/6.
```

这样直接计算去奇异后的核，避免相邻点相减的消减误差。
局部参考坐标上的对数积分矩

```
I_n(x) = integral_{-1}^1 log|x-t| P_n(t) dt
```

由 Legendre Q 函数递推和端点极限精确计算；I_0 使用 x*log(x) 的稳定极限。
这些积分矩与节点到 Legendre 系数的变换结合，生成对数乘积积分权重。
规则余项使用高阶 Gauss 求积。

对于相邻片段，按目标到源片段端点的参数距离递归细分求积区间，正确处理周期接缝。
计算密度仍属于原片段：求积细分不增加未知量。
这与自适应求解中的“增加密度片段”是两种不同操作。

## 自适应

每轮求解后，在每片独立的 p+3 个 Gauss 点及局部坐标 ±0.99、±0.999 处检查边界残差。
指标为每片最大采样残差除以全体检查点上 max|g|。
将指标超过 max(tolerance, 0.3*global_max_indicator) 的片段二分，然后重新构造求解器。
因此既可以细化原始接点附近，也能细化片段内部的欠分辨区域。

这些指标不使用 MMS 的内部精确解，是可用于一般边界数据的后验采样指标；
它们不是连续误差的严格上界。`history[-1]['converged']` 明确报告是否达到目标，
达到最大细分次数时不会隐瞒未收敛状态。回调可查看每轮解和指标。

## Poisson 源项接口

对 -Delta u=f，调用者提供满足 -Delta v=f 的特解 `particular(points)`：
边界求解器取 h=g-v|Gamma，内部求值返回 u=v+w。
不提供 particular 时求解 Laplace 问题。本模块尚不包含任意 f 的体积势计算。

实验使用 f=1，v=-(x^2+y^2)/4，以及非零调和修正

```
w=exp(3x)*cos(3y)+0.1*Re((x+i*y)^7).
```

因此边界求解器没有被零修正绕过。未知密度和边界处理的收敛性是本次验证的核心。

## 独立验证与成本

- 1024 个固定、错开的等弧长点：相对离散 L2 边界误差。
- 180 个额外探针：原始样条节点及其两侧距离 1e-1 至 1e-7 的位置。
- 256 个远离边界的内部点；不宣称任意贴边势求值已经实现。
- 最终解的近节点和部分等弧长探针使用 96 阶求积交叉检查。
- 全局 FFT、固定片段升阶、均匀细分、自适应细分使用同一几何和 MMS。

这是精度参考实现，使用增广稠密 LU，并可复用于固定几何、网格上的多个右端项。
没有使用 SVD，也没有在本版加入 FFT 预条件。N 个密度未知量时，存储 O(N^2)，
LU 构造 O(N^3)，每个新右端项回代 O(N^2)。面板求积阶数和细分因子影响组装常数。
加密网格改变矩阵，需要重新构造 LU。不能将本版描述成整体 O(N log N) 算法。

## 本次实测结果

| 方法 | 密度未知量 N | 独立边界相对 L2 | 包含接点探针的 max误差/max\|u\| |
|---|---:|---:|---:|
| 原全局等弧长 FFT | 1024 | 2.996e-10 | 2.192e-9 |
| 原始 12 片，每片 32 节点 | 384 | 7.112e-12 | 5.430e-11 |
| 每片 12 节点，自适应至 88 片 | 1056 | 1.665e-13 | 9.899e-13 |

自适应独立边界相对误差从初始 144 个密度未知量的 4.758e-9 降到 1.665e-13。
最终内部验证相对误差为 1.601e-15，最终求积加密的归一化最大变化为 2.725e-16。
参数片段宽度从初始 1 变为 1/4 至 1/32，较小片段集中在原始样条接点附近。
终止指标达到 1e-12；增加的常数 c 不计入表中的密度未知量数。

最终固定网格的矩阵构造和 LU 约 7.22 秒，不包含此前自适应迭代及验证求值成本。
相同机器上全局 FFT 的 1024 点构造约 0.17 秒。当前实现优先验证精度，不能据此宣称
分片法在运行时间上更快。17 项相关测试通过，其中 9 项针对本版新增算法。

这组实验支持节点对齐分片和局部加密在既定 C2 几何上达到高精度；没有据此声称所有
数据、所有样条几何都具有全局指数收敛，也没有把未知密度的端点正则性自动视为解析。

相关方法背景：
- https://arxiv.org/abs/1112.6262 （高阶 Nyström 与对数奇异求积）
- https://arxiv.org/abs/1207.6737 （分片光滑边界的局部处理；本实现没有实现 RCIP）
