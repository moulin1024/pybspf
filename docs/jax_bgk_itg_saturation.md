# BGK 碰撞与 ITG 统计饱和诊断

此实现延续标准 BSPF 有限径向 Dirichlet 模型，固定背景温度梯度 aT=4，保留完整 FLR、自洽带状流和非线性括号。新增可调频率 ν 的**线性化 BGK**碰撞，以及平均热通量、空间/速度能谱、同阶段驱动—耗散收支和分窗平稳性检查。没有加入超黏性、额外带状流阻尼、能量修补或背景剖面重置。

## 为什么区分两个 BGK 版本

`plan_collisional_itg(model="local")` 提供回旋中心位置上的局部 BGK：令 H=X+√w Jφ，P 为 √w{1,v,ε−3/2} 的正交投影，

$$C_{local}X=-\nu(I-P)H,\qquad D_{local}=\nu\|(I-P)H\|^2\ge0.$$

它精确保留这三个**回旋中心局部矩**。但有限径向/垂直波数的带状矩也不被弛豫；本项目运行中可形成总自由能近乎不变、热通量持续衰减的状态。不能把这样的能量平台当作非零输运的统计饱和。

默认 `model="gyroaveraged"` 将 BGK 定义在粒子位置再作回旋平均。粒子位置的 Maxwellian 投影保留密度、三个动量分量和总能量。回旋平均后，回旋中心有限波数矩含碰撞输运，不要求在每个回旋中心位置分别为零。碰撞算子转换到回旋动理学变量时需要考虑这种修改；一般原则可参考 [Abel 等的碰撞算子理论](https://arxiv.org/abs/0808.1300)。这里实现的是下述 BGK 投影模型，**没有实现该论文的 Fokker–Planck 或库仑碰撞算子**。

## 回旋平均 BGK 与耗散恒等式

沿用径向谱 FLR 闭合，k⊥²=λr+ky²，a=ρk⊥√(2μ)。令 q 的三列为 √w{1,v,ε−3/2} 在同一 Gaussian 速度求积下的正交基。对每个径向/ky 模态构造四列矩阵

$$B=\left[J_0(a)q_1,\ J_0(a)q_2,\ J_0(a)q_3,\ \sqrt{w}\sqrt{2\mu}J_1(a)\right].$$

最后一列来自垂直动量的回旋平均，不能省略。两个垂直动量分量旋转到相对于 k⊥ 的方向后，只有一个组合对回旋对称分布有非零贡献；其相位不影响 BB†。定义

$$C_{GK}X=-\nu(I-BB^\dagger)\widehat H,$$

再逆变换周期方向。B 是粒子位置正交投影经回旋平均后的矩阵，满足 BB†≤I。建模时检查其最大奇异值，且不裁剪特征值、不修正碰撞功率。离散自由能满足

$$\dot W=P_n+P_T-D,\qquad
D=\frac{\nu}{N_yN_z}\left(\|\widehat H\|^2-\|B^\dagger\widehat H\|^2\right)\ge0.$$

BB† 在有限 k⊥ 下不是幂等投影，不能把 D 错写成 ν||(I−BB†)H||²。k⊥ρ→0 时退化为局部矩守恒 BGK。独立测试用256个回旋角，先回到粒子位置、做五个 Maxwellian 矩的投影、再回旋平均，直接对照 J0/J1 实现。

有限径向区间仍采用此前的 Dirichlet 谱函数闭合，并非真实壁面/鞘层边界；此处未证明有限边界下完整粒子位置全局粒子收支。BGK 为固定 Maxwellian 附近的线性化模型，不是非线性局部 Maxwellian 重构。

## 热通量、能谱和统计判断

温度梯度共轭的热通量定义为

$$Q=\langle g v_{Ex}(\epsilon-3/2)\rangle,\qquad P_T=a_T Q.$$

它按径向积分、周期 y/z 平均归一化，单位是模型单位，尚未换算成 SI 或 gyro-Bohm 单位；除以 Lx 才是径向平均。它也不同于只用 ε 加权的总能量通量。ν 是模型时间单位的倒数。

`integrate_collisional_itg` 在 RK4 相同四个阶段累计 Pn、PT 和正的 D，检查

$$R_W=W(t)-W(0)-\int(P_n+P_T-D)dt.$$

平均 Q 优先从同阶段累计 PT/aT 计算，避免稀疏输出采样的梯形积分偏差；瞬时 Q 独立由相关量计算并交叉核对。

空间谱包含熵型二次量和场能，即完整 W；分别对 ky、径向模态归并。速度谱由正交 Hermite/Laguerre 变换给出熵型二次量 S，记录最高阶能量占比。Parseval 恒等式同时检查谱积分与 W、S 的一致性。

统计窗口分成四个连续子窗，记录每窗 Q、W、带状场能占比、平均注入/耗散和实际 dW/dt。当前平稳性筛查要求：非零平均输运，前后半窗 Q/W 均值变化低于20%，平均注入与耗散失衡低于5%，三种平均谱前后半窗的 L1 相对差低于25%。另要求累计能量收支相对误差小于1e−5。这些门槛是预先定义的诊断标准，不是显著性检验或遍历性证明。四窗标准误仅反映窗口散布；未证明各窗统计独立，不能当作严格置信区间。即使筛查通过，也需要另做相空间分辨率验证。

## 运行与输出

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=jax/src python examples/pde/bgk_itg_saturation.py --nx 33 --model gyroaveraged --end 300 --average-start 150 --out build/bgk_itg_gyro_n33
# 保持所有模型、网格、步长参数相同后可从末态继续：
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=jax/src python examples/pde/bgk_itg_saturation.py --nx 33 --model gyroaveraged --resume --end 600 --average-start 400 --out build/bgk_itg_gyro_n33
```

每10个时间单位写一次 `history.npz` 检查点，保留最终状态、热通量、功率、累计功及三个能谱。`report.json` 保存窗口分析及是否通过筛查；`saturation.png/pdf` 展示演化/热通量/功率/收支；`spectra.png` 展示平均能谱。ν=0 精确退回已有无碰撞模型。


## 已完成的对照与验证

初始扰动幅度0.05，Nx=17/33，Ny=9、Nz=7，Nv=8、Nμ=6，Δt=0.05；所有径向自由度均保留，Ny/Nz 使用严格2/3截断。局部 BGK 的 ν=0.15 对照推进到600，400–600平均 Q≈1.52e−6且继续下降，未通过平稳性筛查；Ny增到15和ν增到0.3的局部对照也没有把能量平台变为稳定的非零输运。

回旋平均 BGK 的 Nx=17、400–600窗口：

| ν | 平均 Q | 四窗标准误（非置信区间） | 平均注入 | 平均耗散 | 平均功率失衡 | 最大能量收支残差 / max W |
|---:|---:|---:|---:|---:|---:|---:|
|0.15|2.29329|0.28287|9.17316|8.82116|3.84%|4.87e−8|
|0.30|3.12599|0.48023|12.50394|12.20916|2.36%|7.68e−8|

两组均通过当前平稳性筛查，三种平均谱的前后半窗差分别最大8.94%和11.93%。ν=0.15的四个窗口 Q 为2.90642、1.66160、1.99841、2.60673，显示仍有显著窗口散布；不能由上述两点断言精确的碰撞频率标度。

平均注入与耗散的有限窗口差由端点储能变化解释，不是数值收支缺陷。数值残差 R_W 在同阶段累积功之后才计算，两者必须区分。

速度谱最高 Hermite 或 Laguerre 阶的联合能量占比约3.22%（ν=0.15）和0.98%（ν=0.3）。当前结果验证的是有限离散模型的统计饱和，尚未证明速度网格、周期模态数和径向平均热通量的收敛。径向谱尾也只作分辨率诊断，不能替代网格加密。

共28项相关测试通过：原无碰撞/非线性回归、BGK局部矩和频率、Maxwellian零空间、回旋角独立投影、长波极限、非负耗散、同阶段累计功收敛，以及识别“能量平坦而热通量仍衰减”的反例。

平均注入8.674937、平均耗散8.606467，相差0.789%；其差0.068470与该窗口的平均储能变化率一致。最大累计预算残差/max W为5.08e−8。谱Parseval相对误差6.09e−14。径向最后三个模态的平均自由能占比0.0109%，速度最高阶联合占比3.27%。17点与33点平均Q相差约5.7%，处于本次窗口散布范围内，但还不足以证明网格收敛。
