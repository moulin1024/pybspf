# 解析法向窄带延拓的独立验证

实现 `src/pybspf/normal_continuation.py`，实验
`examples/pde/normal_continuation_validation.py`。本阶段隔离延拓误差：
输入仅为内侧带函数值，包括边界端点；没有真实梯度、Laplacian 或外域值输入。
使用同一随机波 MMS（种子20260918，64个连续波数，最高4π/12π），
两种周期三次 B-spline 域（凸域和非星形域）。尚未接入未知场 PDE。

## 构造

精确几何 X(t,r)=C(t)+r n(t)，r<0 为内侧。内侧宽度 w 为
0.02、0.01、0.005；法向 Chebyshev–Lobatto 插值次数6、8、10、14，
每样条段切向次数24、36。先沿法向作多点一维多项式延拓，切向插值将这些
法线上的构造组成可求导场。它是研究用的局部多项式基线，**不是完整
FC-Gram 算法，没有平滑归零、Cartesian 网格转移或 Fourier 拟合**。

所有导数均解析计算。令 J=[X_t,X_r]，局部场 q(t,r)，则

    grad_x u = J^(-T) grad_(t,r) q
    Hess_x u = J^(-T) [Hess_(t,r) q − sum_i (grad_x u)_i Hess_(t,r) X_i] J^(-1).

Laplacian 为物理 Hessian 的迹，包含曲率相关项，不把法向二阶导数直接
当成 Laplacian。n'、n'' 从 C'、C''、C''' 求出；三次样条接点使用分段迹。

独立切向点每段43个（偏移0.371/43），独立法向层分别位于
内侧 −0.873w、−0.413w、−0.071w，边界0，外侧0.113w、0.287w、0.479w，
以及较远外侧0.613w、0.797w、0.979w。误差是这些点的离散相对二范数，
不是精确面积积分范数；梯度合并两个物理分量计算。

## 结果

法向8次、切向36次、w=0.01，最高波数12π：

|区域与验证带|值|梯度|Laplacian|
|---|---:|---:|---:|
|凸域，内侧|2.18e-15|9.99e-14|7.86e-12|
|非星形，内侧|2.55e-15|1.04e-13|9.38e-12|
|凸域，边界|2.17e-15|5.66e-13|6.86e-11|
|非星形，边界|2.46e-15|4.87e-13|7.68e-11|
|凸域，外侧半宽内|3.81e-12|3.48e-10|1.13e-8|
|非星形，外侧半宽内|3.83e-12|3.67e-10|1.47e-8|
|凸域，外侧半宽至全宽|2.07e-10|1.18e-8|2.47e-7|
|非星形，外侧半宽至全宽|2.18e-10|1.31e-8|3.37e-7|

完整结果有384行（两域、两波数、三宽度、四法向次数、两切向次数、四验证带）。
提高法向次数不总是改善精度，缩小宽度也会进入导数误差平台。
这与外推的误差放大相符：外侧 r=0.5w，法向插值映射的无穷范数
在8次时约1.88e4，14次时约5.08e7；r=w 时分别6.66e5、2.61e10。
这些是任意输入误差的最坏放大倍数，不是随机误差实测值。
二阶导数还包含 w^(-2) 缩放。因此精确 MMS 输入得到小误差，不能证明
带数值误差的未知场输入也足够稳定。

样条接缝附近 t=k±1e-10、r=0.479w 的最大绝对差（值/梯度分量/Laplacian）为
凸域9.34e-10 / 3.52e-8 / 4.38e-5，非星形1.26e-9 / 8.83e-8 / 4.54e-4。
这包含两个相邻位置的真实变化，不是严格极限跳量；Laplacian 的接缝
差异说明逐段独立插值还需要连续性控制，不能仅凭非接缝均方误差接受算子。

## 几何及验证限制

在所测带宽内，归一化 Jacobian 最小值为凸域0.967、非星形0.715，均为正。
对40001个边界样本的最近距离筛查未发现更近的非局部边界（阈值1e-5）。
这是离散几何检查，不是全局法线不交叉的数学证明。

解析几何导数的独立有限差分检查、二次物理场的梯度和 Laplacian 检查、
周期参数边缘检查，两域共2个组合测试通过；ruff 通过。

当前可确认局部精度潜力，但稳定性与接缝控制尚不满足直接接入未知场的要求。
下一步应将这一可复现多项式基线与正则化一维延拓/FC-Gram 比较，增加输入
扰动测试及接缝连续性约束，再构造全域延拓矩阵和未知场方程。
