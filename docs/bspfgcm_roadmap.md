# BSPFgcm：面向理想水地球的开发路线

日期：2026-09-19。本文是架构建议和验收计划，不表示所列模块已经实现。

## 目标与范围

以 pybspf 的 B 样条加 Fourier 残差修正、张量算子及压力求解能力为数值基础，
构建能运行理想全球海洋、大气及双向耦合试验的 BSPFgcm。
参考 MITgcm 的方程组织、物理过程接口和验证实验，独立设计 BSPF 离散。
MITgcm 使用有限体积及压力方法；将它的差分导数逐个替换成 BSPF 导数，不能自动获得
一致、守恒、稳定的高阶 GCM。[MITgcm 概览](https://mitgcm.readthedocs.io/en/latest/overview/overview.html)

最终目标按“三维湿大气 + 三维动力海洋，全海洋覆盖球面”定义。
依次区分固定 SST 水地球、板块混合层海洋水地球、完整动力海洋水地球。
前两者是必需的中间检查点，不能当作最终目标已经完成。
首版无大陆、海底地形、海冰、生态化学和同化，固定地球半径与转速；采用理想化辐射。
无海冰阶段应选择避免结冰的试验参数并监测最低温，不能宣称可模拟冰冻气候。
闭合球面没有南北墙，现有 beta 平面双环流中的盆地西边界流不会直接延续为水地球环流。

## 方程路线

### 三维过程试验：旋转 Boussinesq 箱体

z 向上，去除参考静水压力，令 pi=p'/rho0：

\[
\partial_t\boldsymbol u+\boldsymbol u\cdot\nabla\boldsymbol u
+2\boldsymbol\Omega\times\boldsymbol u
=-\nabla\pi+b\boldsymbol e_z+\mathcal D_u+\boldsymbol F,
\quad \nabla\cdot\boldsymbol u=0,
\]
\[
\partial_t C+\nabla\cdot(\boldsymbol u C)
=\nabla\cdot(K_C\nabla C)+Q_C.
\]

海洋 C=(T,S)，先用线性状态方程 b=g[alpha(T-Tref)-betaS(S-Sref)]。
它适合理想试验；非线性海水状态方程随后独立加入。
局地大气过程试验可用位温、比湿及虚位温构造浮力；需要明确参考层结和压力，
不能把局地 Boussinesq 湿气体当作整个大气柱。
真实浮力作用在竖直动量中；在静力模式中进入静力压强，再影响水平流动。

### 全球主线：静力原始方程

全球首版采用静力近似，仍是有垂直结构、垂直输运及三维环流的模型。
海洋用 z 坐标起步，刚盖验证后加入自由表面，再考虑 z*；大气采用 sigma/p* 类
压力坐标，包含地面气压、理想气体热力学、位温与水汽。
两者共享几何、算子、求解和过程接口，分别定义状态方程、质量权重、边界条件及预算。
MITgcm 的通用垂直坐标组织值得借鉴，但无需在首版强行把两个物理核心塞进同一个 RHS。
[MITgcm 连续方程](https://mitgcm.readthedocs.io/en/latest/overview/overview.html#continuous-equations-in-r-coordinates)

非静力箱体是一条过程验证线；全球非静力作为后续扩展，不作为水地球首版的前置要求。

## BSPF 离散的五个验收门槛

1. **兼容算子。** 用共同质量矩阵和几何权重构造弱散度 D、梯度 G，满足离散分部积分。
   闭合/齐次无通量边界下要求 G=-Mu^-1 D^T Mp；边界功单独保留。
   压力 Schur、压力零模和速度约束由同一组算子定义，检验伪压力模态。
   现有 collocation 压力核心与新弱算子不能未经验证直接混用。
2. **守恒输运。** 层质量、温度/焓、盐、水汽使用一致质量通量。
   常数保持、全域积分和界面抵消必须独立验证；近谱导数精度不替代守恒证明。
3. **平衡保持。** 静水静止、地转平衡和层结背景应能维持；静力积分和压力梯度
   使用一致离散。非均匀垂直坐标进一步要求几何守恒，避免大背景量相减产生假流。
4. **非线性与有界性。** 从过积分/去混叠和能量稳定形式开始，独立检查非线性采样。
   对比湿、层质量的保正措施必须守恒并计入误差；不允许静默 clip 丢水。
   非光滑锋面、凝结切换及限制器启用时，不承诺全局近谱精度或统一四阶时间收敛。
5. **求解成本。** 保留逐轴和 matrix-free 运算，不组装全三维稠密矩阵。
   球面度量与变系数通常破坏精确张量可分离性；将矩形直接逆用于块预条件，
   外层采用 Krylov/多重网格并验证性能。弱对称正定系统才使用 CG，否则选合适求解器。

“BSPF 版本”以离散空间、边界处理及核心算子为特征；周期方向 Fourier 是自然特例，
不要求物理参数化、I/O 和所有辅助计算也采用 BSPF。

## 球面几何

建议主线使用六面 cubed-sphere，每面参考坐标上采用张量 BSPF，垂直方向单独分辨。
度量、Jacobian、矢量基旋转和跨面法向通量必须进入弱形式。
选择并验证一种跨面耦合：共享通量的 mortar/弱接口是候选；不把边缘点值插值当作守恒。
角点、旋转向量和重复节点的积分权重也需要测试。

先在双平面 patch 上验证接口，再做球面标量输运和浅水方程。
对光滑解分别做固定 patch 数加密与 patch 数加密，确认接口没有将全局误差降为低阶。
若接口路线未通过验收，可评估经度 Fourier + 纬度 BSPF，但需另解极点正则性与 CFL；
不能把经纬度矩形直接首尾相连当作球面。

## 时间推进与耦合

小规模光滑过程试验先保留每阶段满足约束的 RK4，作为时间精度基线。
压力是约束，不只是一个“快物理过程”；每个需要的阶段都应满足相应约束。
全球模式的海洋外重力波、垂直扩散及大气重力波会引入刚性：规划一致的 IMEX/隐式
求解或经过验证的模态分裂。新增隐式过程时，不能把当前 MRI 算法随意套在低阶子步外，
仍声称四阶。应重新检查加性阶条件、阶段相容性和完整系统收敛。

海气交换返回同一组界面应力、显热、潜热及淡水通量；两侧在各自离散质量权重下
收到等量反向的积分。不同网格采用守恒映射，矢量应力还需坐标旋转。
保留当前 MRI “双方界面交换放入同一快 RHS”的原则，但重写三维状态和预算接口。
界面交换快、海洋内部慢的分裂是否划算，要按实际稳定性和 RHS 成本测量。

水地球需闭合蒸发—水汽—凝结—降水—海洋水量/盐度反馈。
饱和调整必须同时处理潜热和水汽；温度及潜热不能重复记账。
全系统预算至少包括质量、水、盐、热力能、动能与势能，以及外部辐射和摩擦耗散去向。
现有二维“显热+水汽潜热”收支不能直接当作三维总能量守恒。

## 最小湿物理

先做干大气 Held–Suarez，隔离动力核心；随后依次加入水汽输运、守恒凝结/降水、
海面 bulk 交换、垂直边界层扩散、理想化灰辐射。
最简降水可令凝结水即时落海，但必须声明无云水储存和云辐射反馈。
静力粗网格无法解析深对流，需明确对流调整/简化参数化或声明只包含大尺度凝结。
首版不必复刻 MITgcm AIM 全部物理。
[Held–Suarez 教程](https://mitgcm.readthedocs.io/en/latest/examples/held_suarez_cs/held_suarez_cs.html)
和 [GFDL 理想湿模型](https://www.gfdl.noaa.gov/idealized-moist-spectral-atmospheric-model-quickstart/)
提供分层验证参照。

## 里程碑与退出条件

| 阶段 | 可运行交付物 | 通过标准 |
| --- | --- | --- |
| M0 数值契约 | BSPFgcm 包接口、单位/坐标约定、制造解与预算工具 | 常数保持、伴随关系、边界通量、重启一致性 |
| M1 三维旋转分层箱体 | u,v,w,p,T,S；刚盖、周期通道/固壁两类边界 | 空间与时间分开加密；静水保持、惯性振荡、内重力波、热成风及浮力能量转换 |

| M3 三维静力海洋 | 分层双环流、斜压通道、球面全海洋 | 温盐/体积预算、斜压增长率、自由表面波、合理热输运 |
| M4 三维干大气 | 球面 Held–Suarez | 质量预算、静水/地转平衡、急流及纬向平均环流的统计收敛 |
| M5 湿水地球 | 固定 SST，再接板块混合层海洋 | 水循环、潜热闭合、TOA/海面收支及降水/温度统计 |
| M6 完整耦合水地球 | 三维湿大气 + 三维动力海洋 | 多速率时间误差、跨组件预算、连续重启、长时间统计与海洋热含量漂移 |

顺序：M0 后尽早推进 M1 与 M2；M3/M4 都依赖球面算子，M5 依赖 M4，M6 依赖 M3/M5。
本表描述依赖关系，不假定已有多人并行开发。
每阶段先冻结方程、边界、单位、误差范数和阈值，再运行验收，不根据结果放宽阈值。
混沌流场的长期比较使用时间平均、方差、谱和收支，不要求与 MITgcm 逐点相同。
24 小时只作为冒烟测试，不证明气候平衡；深海平衡需依据热含量、TOA 能量失衡等
诊断确定，不能预先用固定短时长宣称完成。

## 建议的软件边界

先在本仓库增加独立 `bspfgcm` 命名空间，复用 `bspf_jax`，稳定后再决定独立发布。
以下为建议目录，尚未创建：

```text
bspfgcm/
  geometry/       # Cartesian、patch、球面度量和接口
  operators/      # 弱导数、质量、输运、投影及预条件
  dynamics/       # boussinesq3d、hydrostatic_ocean、primitive_atmosphere
  thermodynamics/ # 海水 EOS、位温/虚温、饱和关系
  physics/        # 混合、辐射、凝结、对流与外部强迫
  coupling/       # 阶段通量、守恒映射、预算
  timestepping/   # RK/MRI/后续 IMEX 的明确算法接口
  diagnostics/   # 守恒、平衡、谱、环流和性能
  io/            # 配置、带版本重启、NetCDF/Zarr
verification/    # 每项固定配置、预期量、独立误差检查
```

纯 RHS、静态 plan 与动态 state 分离；每个物理过程返回 tendency 和预算贡献。
边界通量统一为带方向和单位的对象，避免各模块自行约定正号。
记录提交/配置/算子参数、随机种子、时间方法、求解容差和后端。
先选择 JAX FP64 为可复现实验后端，保留 NumPy 参考检查；GPU/MPI 性能属于后续测量任务。

建议先试算箱体 32×32×16 / 64×64×32，以及球面每面约 16²/32²、20–30 垂直层。
这些是成本探测网格，不是已验证的 GCM 分辨率。统计预计算、编译、RHS、压力、
接口通信、I/O、峰值内存及“模拟年/墙钟日”；多速率阶段缓存也要算入内存。
先达到数值门槛，再依剖析决定分块、变换压缩、多设备或多进程方案。

## 立刻开始的工作包

下一项具体实现建议为 **M0 + M1 的三维旋转分层箱体**：

1. 固定 z 向上、单位、质量内积与线性海水 EOS；定义三维状态。
2. 审核并补齐三维压力边界/零模，建立成对 D/G，不混用不相容算子。
3. 加入温盐守恒输运、Coriolis 与竖直浮力，每个 RK 阶段更新密度和压力。
4. 实现静水静止、解析内波、非线性制造解和预算验证。
5. 单独验证时空收敛与重启，输出一份可重复运行的验收报告。

该工作包完成后才称为 BSPFgcm 的首个三维动力原型；球面浅水是紧接着的架构门槛。
