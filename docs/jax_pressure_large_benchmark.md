# 1024² / 2048² 压力直接法基准

2026-09-18。比较稠密直接法、旧 grouped 压缩布局和新 layered 压缩布局。没有更改离散参数、压缩容差或求解容差。

- JAX CPU，float64/complex128；均匀 [0,1]² 网格。
- q=9、样条数32、degree=13；Chebyshev端点拟合16样本、12模态。
- 压缩容差1e-12、叶块上限16、保护8个模态。
- 所有后端都是0次迭代精修，没有外层迭代或自动回退。
- 编译预热后同步执行9次，报告中位数；完整投影不含壁面梯度补全。
- 另用平滑/随机已知压力构造兼容右端，进行带壁面梯度补全的精度检查。
- 因子字节数只统计单轴正逆变换表示，包含索引和保护模态，不是整个计划或峰值内存。

复现：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
MPLCONFIGDIR=/tmp/pybspf-mpl \
python3 scratch/benchmark_compressed_pressure.py \
  --sizes 1024 2048 --out build/layered_pressure_benchmark_large
```

原始结果与计时图位于 `build/layered_pressure_benchmark_large/`。这是二维实测，不应直接当作三维耗时或GPU性能。

## 时间

| 网格 | 稠密完整投影 | 旧分组完整投影 | 新按层完整投影 |
|---|---:|---:|---:|
| 1024² | 0.301908 s | 0.440867 s | 0.462132 s |
| 2048² | 2.368632 s | 2.177543 s | 2.183108 s |

| 网格 | 稠密张量逆 | 旧分组张量逆 | 新按层张量逆 |
|---|---:|---:|---:|
| 1024² | 0.166943 s | 0.316641 s | 0.357237 s |
| 2048² | 1.411741 s | 1.276151 s | 1.177902 s |

1024²时两种压缩布局仍慢于稠密。2048²时，新按层布局的张量逆耗时比稠密减少约16.6%，完整投影减少约7.8%；新旧压缩布局完整投影只相差约0.3%，本轮应视为基本持平。这是本机单次基准的中位数，不是跨机器性能保证。


## 存储与设置成本

| N | 稠密单轴正逆变换 | 旧分组变换 | 新按层变换 | 新按层／稠密 | 旧→新批次 |
|---|---:|---:|---:|---:|---:|
| 1024 | 31.88 MiB | 12.79 MiB | 14.02 MiB | 44.0% | 43 → 14 |
| 2048 | 127.75 MiB | 30.51 MiB | 31.53 MiB | 24.7% | 58 → 16 |

N=1024：稠密计划设置 22.25 s；两种压缩布局额外设置合计 6.42 s。设置成本不含在上表稳态耗时中。

N=2048：稠密计划设置 47.69 s；两种压缩布局额外设置合计 41.67 s。设置成本不含在上表稳态耗时中。

## 精度：2048²未通过全部检查

**2048²时，三种后端的平滑压力恢复和随机压力恢复都未通过默认残差判据。稠密基准也失败，因此不能把上述耗时当作已经满足精度要求的通用压力直接法性能。** 没有放宽判据，没有用迭代精修掩盖失败。

| N | 后端 | 随机向量投影通过 | 平滑压力通过 | 平滑压力相对误差 | 随机压力通过 | 随机压力相对误差 |
|---|---|---|---|---:|---|---:|
| 1024 | 稠密 | 是 | 是 | 1.585e-09 | 是 | 2.461e-09 |
| 1024 | 旧分组 | 是 | 是 | 1.585e-09 | 是 | 2.462e-09 |
| 1024 | 新按层 | 是 | 是 | 1.585e-09 | 是 | 2.461e-09 |
| 2048 | 稠密 | 是 | **否** | 1.314e-07 | **否** | 8.443e-05 |
| 2048 | 旧分组 | 是 | **否** | 1.314e-07 | **否** | 8.462e-05 |
| 2048 | 新按层 | 是 | **否** | 1.314e-07 | **否** | 8.462e-05 |

随机原始向量的投影与随机已知压力的恢复是两个不同测试。2048²的投影测试通过，并不等于压力恢复测试通过。新按层投影场相对稠密结果的差异在1024²为1.01e-13、2048²为2.52e-11。

2048²的平滑压力绝对最大Schur残差约9.2e-5，三种实现接近；随机压力相对误差约8.4e-5。误差已经出现在零精修稠密基准中，不能单独归因于压缩；具体来源尚未定位。下一步应优先检查消元、近零模态和壁面补全的数值稳定性，而不是继续以压缩比例或耗时作为唯一指标。

本次只扩展测试规模并增加基准进度/中间结果记录，没有修改生产求解算法。
