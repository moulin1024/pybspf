# 固定 Nx=33 的 BGK 速度分辨率与统计窗口扫描

这组试验只检查速度求积收敛，不等同于完整五维空间—速度网格收敛。径向使用标准 BSPF：Nx=33，31 个满足端点条件的径向模态，384 个积分点。Ny=9、Nz=7 以及严格 2/3 Fourier 截断保持不变。

## 控制参数与复现

四档 Gauss–Hermite / Gauss–Laguerre 求积节点数为 `(8,6)`、`(12,8)`、`(16,12)`、`(24,16)`。所有算例使用相同的连续初始扰动（幅度0.05）、回旋平均线性化 BGK、ν=0.15、温度梯度 aT=4。速度加密时同步重算 FLR 与碰撞矩，保持碰撞频率不变。

计划共同推进到 t=1200，主统计窗口为 [400,1200]，长度800；同时分析 [400,600] 与 [400,800]。相对之前 [400,600] 的200长度窗口，目标采样时间扩大4倍。热通量使用径向积分的模型单位，未除以径向域长12。用户已于2026-09-22要求终止 CPU 扫描；当前停止状态见末节。

在仓库根目录运行（需安装 JAX 项目依赖）：

```bash
export PYTHONPATH=jax/src
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
python examples/pde/scan_bgk_velocity.py --jobs 4
python examples/pde/report_bgk_velocity_scan.py
```

中断后使用 `scan_bgk_velocity.py --jobs 4 --resume`。每10时间单位原子保存一次检查点。四个目录在 `build/bgk_velocity_scan/v*_m*_dt01/`；汇总是 `velocity_scan.json`、`velocity_scan.png` 和 `window_extension.png`。

## 时间步长与标准 BSPF 算子的等价加速

共同使用 RK4 的 Δt=0.1。在最细 `(24,16)` 速度网格上，从同一投影后的饱和初态分别用0.1与0.05推进5个时间单位，热通量时序相对 L2 差为5.63e−7，末态差为1.54e−4；较大步长的功收支残差/max W 为1.42e−6。这是短段时间步长对照，不是长时间统计输运的时间步长收敛证明。完整长时运行另行报告累计预算残差。

为降低速度扫描耗时，预先计算标准 BSPF 的径向三线性积分

\[
T_{ijk}=\sum_q w_q Q_i(x_q)\,Q_j'(x_q)\,Q_k(x_q).
\]

以31³的径向张量收缩代替对每一个速度列重复变换到384个积分点。没有改变积分节点、BSPF 基函数、边界条件或保留模态，也没有组装完整相空间矩阵。生产求解器提供 `--radial-kernel tensor` 选项，默认 `quadrature` 路径保留作对照。严格2/3投影使保留 Fourier 模上的乘积法则重写与原交替弱括号等价。测试比较右端项、有限步轨迹、功积分和自由能恒等式。

## 平均量与统计不确定度

用同一 RK 阶段累计的温度梯度驱动功计算每块热通量均值：

\[
\overline Q_j=\frac{\mathcal W_T(t_{j+1})-\mathcal W_T(t_j)}{a_T(t_{j+1}-t_j)}.
\]

因此无需由输出的瞬时热通量再作稀疏时间求积。输出间隔1不等于独立采样间隔。

报告25、50、100、200长度的不重叠块均值、标准误、相邻块相关性及 Student-t 区间。主800长度窗口分别有32、16、8、4块；在不少于8块的候选中选取最宽区间，同时保留200长度/4块的敏感性结果。这里的“95%区间”依赖平稳且块间近似独立的假设；取候选中最宽区间只是保守的敏感性处理，不保证无条件95%覆盖率。

相邻分辨率比较使用均值差的 Welch 区间，除以细网格的样本均值作相对刻度。整个区间落在 ±5% 内才支持该精度的等效性，单纯误差条重叠或点估计相近都不够。不同网格使用同一连续初态，没有独立种子重复；独立性近似及长相关时间仍可能影响置信度。

共同检查平均热通量与 W 的前后半窗变化、平均谱漂移、速度谱尾、累计功收支，以及有限窗口的平均注入—耗散差。后者必须与端点储能变化率一起解释，不能直接当作数值误差。
