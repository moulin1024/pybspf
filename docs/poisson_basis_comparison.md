# 相同曲边 Poisson 离散下的近似空间对照

运行脚本：`examples/pde/compare_poisson_bases.py`。
绘图脚本：`examples/pde/render_poisson_basis_comparison.py`。
完整结果、图和 CSV 位于 `build/poisson_basis_comparison/`。

## 实测结果解读

主阈值 1e-13，N=65，同一独立均匀点云上的相对 H2 误差如下。
左数为数值最佳 H2 拟合，右数为实际 PDE 解；纯 B-spline 固定 p=13。

| MMS | BSPF：拟合 / PDE | Fourier：拟合 / PDE | B-spline：拟合 / PDE |
|---|---:|---:|---:|
| 八次多项式 | 1.77e-13 / 5.25e-10 | 2.77e-10 / 2.10e-9 | 5.16e-14 / 1.64e-11 |
| 局部高斯峰 | 6.63e-10 / 1.37e-8 | 9.99e-15 / 1.29e-12 | 2.62e-7 / 1.35e-6 |
| 有理函数 | 1.81e-8 / 6.74e-8 | 1.78e-8 / 1.26e-6 | 4.88e-6 / 4.90e-6 |

- 多项式上样条的优势明显，而且 p=13 空间已经在 N=17 精确包含本测试的多项式。
  BSPF 在 N=33 也已达到接近机器精度的解误差，Fourier 在该 N 的解误差约 1e-7。
- 高斯峰不是用有限 Fourier 和定义的，但 Fourier 仍表现最好。因此原先高波数随机波的
  Fourier 优势不能全部归因于 MMS 构造方式；也不能从这两个例子外推到所有函数。
- 有理函数上 BSPF 与 Fourier 的最佳拟合几乎相同，实际 PDE H2 误差却相差约 19 倍。
  这一差异发生在 PDE 离散与数值求解层，不能宣称 BSPF 的空间逼近能力强了 19 倍。
- 部分 PDE 误差明显高于最佳拟合，且多项式误差在 N=65 反而高于 N=33。
  当前实现仍有离散稳定性、求积与浮点误差方面的改进余地。

共同稠密实现的 N=65 首次 PDE 构造：BSPF 178.6 s、Fourier 93.3 s、B-spline 90.7 s；
已有分解的单 RHS：161 ms、163 ms、136 ms。独立的 H2 拟合诊断构造分别约
414.5 s、342.9 s、326.2 s；它们不属于实际 PDE 求解的必要成本。

完整 N=17/33/65 数据与阈值敏感性见 `build/poisson_basis_comparison/summary.md`。
新增函数的三列收敛图为 `non_fourier_convergence.png`，原随机波图为 `convergence.png`，
成本图为 `cost.png`。这些是固定参数下的对照，不是空间家族的普适排名。

共同 Q24、27120 点的加密验证已经完成，主要结论保持：高斯峰 PDE H2 误差分别为
BSPF `1.57e-8`、Fourier `1.51e-12`、B-spline `1.49e-6`；有理函数分别为
`5.68e-8`、`1.40e-6`、`4.89e-6`。有理函数最佳拟合的 H2 误差则分别为
`1.89e-8`、`1.97e-8`、`4.87e-6`，仍能清楚区分空间逼近与 PDE 求解的影响。
主图保留原先共同的 8159 个独立均匀点，不用加密结果替换个别空间的主表数字。

验证状态：9 个参数组合均完整，270 条误差/阈值记录；全部保存结果的独立验证坐标与
精确函数值逐项一致；`test_poisson_basis_comparison.py` 的 9 项检查通过。

## 固定项与变化项

三种空间均使用 `benchmark_domains()[0]` 的凸、闭合三次 B-spline 曲线作为物理边界，辅助矩形为 `[-1.2, 1.2]^2`。几何样条与场的近似基是不同对象。辅助矩形不施加物理 Dirichlet 边界条件。

每方向维数 `N=17,33,65`，总系数数目为 `N^2`。只更换一维近似空间；积分、拟合、验证代码完全共用。

| 空间 | 一维定义 |
|---|---|
| BSPF | 原有 unrestricted `_stream_line`，13 次样条端点修正，Chebyshev 端点处理参数 P=M=12 |
| Fourier | 常数以及成对的实正弦、余弦，最高频率 `(N-1)/2`，周期 2.4 |
| B-spline | 13 次、均匀内部节点、两端各重复 14 次的开放节点向量，恰好 N 个基函数，无额外端点约束 |

纯 B-spline 有 `N-13` 个非零长度节点区间。本实验固定次数 13，不能外推为所有次数、节点分布或自适应 B-spline 的结论。

BSPF 的“13 次”指端点修正样条的次数，不表示另加一套独立的 13 次多项式自由度。
它仍是端点投影与 Fourier 部分耦合后的 N 维空间，多项式再现能力应由实际结果检查。
同一个 N 也不意味着三个空间有相同的节点间距、有效带宽或限制到物理域后的数值秩。
因此同时记录保留秩，并绘制缩放后奇异值谱；相同总系数预算是这里的公平性定义。

一维空间在全矩形区间的质量内积下正交归一，并对角化一阶导数刚度。Fourier 天然满足这一条件。这个变换只改变坐标，不改变近似空间。

共同设置：

- 物理体积积分：`volume_rule(16)`，12032 点，同一曲线精确切片与端点映射；不是简单掩膜矩形求积。
- 边界积分：1024 个等弧长点，完全相同的 Fourier 离散 `H^(3/2)` 范数。
- 独立内部验证：`interior(domain,127,131,0.613)`，8159 个偏移均匀网格点。
- 独立边界验证：2048 个等弧长点，偏移 0.371。
- 两个解析随机波 MMS：种子 20260918，64 个连续随机波向量，波数带分别 `[pi,4pi]`、`[pi,12pi]`。
- 三个不以有限 Fourier 和定义的 MMS：下述非周期多项式、局部高斯峰、有理函数。五个右端项共享同一次分解。
- 双精度线性代数；BSPF 原有构造内部使用高精度后转换为双精度。
- 相同全矩形 H2 右缩放；相同相对 SVD 截断阈值 `1e-11,1e-13,1e-14`。主表与主图取 `1e-13`。

独立内部误差使用相同均匀点云上的离散范数近似连续相对范数。记录训练求积误差，以检查独立点与训练点的表现是否一致；不把点云结果称为严格连续误差证书。

额外用 Q=16、20、24、32 对精确解 H2 范数作积分检查，保存于
`exact_norm_quadrature_check.json`。Q16 相对 Q32 的范数差分别约为：
低波数 `5.4e-8`、高波数 `1.8e-5`、多项式 `8.9e-11`、高斯峰 `3.6e-5`、
有理函数 `7.7e-7`。所以共同的 Q16 规则并不意味着所有积分都达到机器精度。
最小二乘的点值残差可以远小于该积分差，但这些实验不是连续最优逼近的认证；
严格认证还需要对完整误差和离散稳定性作求积加密。
例如 N=65 Fourier 的离散 H2 限制矩阵最大奇异值约为 1.40，而使用精确积分时，
从全矩形到子域的同阶 H2 范数限制算子范数应不超过 1。这也说明 Q16 对某些最高频方向
存在明显积分偏差，不能把本实验包装为连续最优逼近的严格比较。独立验证及额外 Q24
误差检查用于区分实际解精度和训练求积的表现；下一步若要认证最优性，应对三种空间
共同加密求积并重做拟合，而不是只给某一个空间更高阶积分。

### 避免单一 MMS 家族偏向

随机波由有限个解析平面波叠加而成，确实适合 Fourier 近似；波数不落在计算基的频率格点上，并不消除这种函数类别上的偏向。因此这组结果只说明振荡函数类的表现。

另外三组直接在物理空间定义，分别为：

```
polynomial: u = (1 + 0.3x - 0.2y)^8 + 0.2xy
gaussian:   u = exp(-d^T Q d / 2),
            d = (x-0.27, y+0.13), Q = [[100,25],[25,60]]
rational:   u = 1 / (1 + d^T Q d),
            d = (x-0.13, y+0.09), Q = [[9,2],[2,16]]
```

三者均使用解析梯度和 Hessian 生成 forcing，导数通过有限差分独立检查。高斯峰局部化且各向异性；有理函数在实域光滑但具有有限距离的复奇点。它们也都具有 Fourier 表示，因此“不是 Fourier 和构造”不等于“Fourier 应该表现差”。

多项式本身落在 13 次样条空间中，是有意设置的精确再现对照，不能把这组对样条有利的结果当成普遍胜负。BSPF 是否在给定离散参数下以足够精度再现该多项式，也由实验检查。

函数尺度与参数在比较前固定，不根据各个空间的结果分别调整；报告每类结果而不混合成一个总分。有限的 MMS 集合不能证明任一空间对所有解最优。

## 两个不同实验

令 `u_N(x,y)=sum C_ij phi_i(x) phi_j(y)`。

**PDE 实验**仅输入 `f=-Delta u_exact` 和真实物理边界上的 `g=u_exact`，求解

```
min ||-Delta u_N - f||^2_L2(Omega)
  + ||u_N - g||^2_H^(3/2)(Gamma).
```

不使用内部精确解、梯度或 Hessian 作为 PDE 约束。脚本为复用解析公式而从精确 Hessian 生成 f，这与 MMS 的解析 forcing 等价，已有测试验证。

**最佳 H2 逼近诊断**单独使用已知 MMS 的全部内部 jets，求解

```
min integral_Omega [e^2 + ex^2 + ey^2 + exx^2 + 2 exy^2 + eyy^2],
e = u_N - u_exact.
```

后者没有添加边界惩罚，是近似空间诊断，不是可用于未知解的 PDE 算法。采用相同的 H2 缩放和 TSVD；因此应称为“离散、正则化的最佳 H2 逼近诊断”，不能声称得到未截断空间中严格的连续最优值或误差下界。在不同求积与验证点上，也不要求该诊断的误差永远小于 PDE 解误差。

H2 缩放的 Cholesky 因子 R 满足

```
||R vec(C)||^2 = ||u_N||^2_H2(B),
G = I + K (x) I + I (x) K + J (x) I + I (x) J + 2 K (x) K,
K_ij = integral phi_i' phi_j',
J_ij = integral phi_i'' phi_j''.
```

这里 `(x)` 表示 Kronecker 积；对 BSPF 和 B-spline 使用真实 J，不能将 J 替换成 K²。然后对 `A R^-1` 进行 SVD。报告保留秩、全矩形 H2 范数和阈值敏感性，避免只看一个误差数值。

## 成本定义与适用范围

串行运行三个空间，BLAS 单线程。每个 N、每种空间分别冷构造一次；低波数和高波数共享同一次 SVD，三个阈值也共享该 SVD。

`setup_seconds` 包含一维基构造、训练点基求值、H2 缩放、矩阵组装、右缩放、SVD。排除共同的几何求积、MMS 数据生成和独立验证。H2 诊断也沿用预先构造的边界基，所以其 setup 中包含一项它实际不需要的边界基求值成本。

`repeated_rhs_seconds` 为已有 SVD 后，单 RHS 求解的 5 次中位数，不包含 f/g 采样和输出网格求值。实现保留完整 U、V，在 RHS 求解时选取截断部分；不是针对各空间分别优化的最快实现。

`matrix_bytes` 仅为显式系统矩阵大小，**不是峰值内存**。N=65 时 PDE 矩阵为 `13058 x 4225`，约 0.441 GB；H2 诊断矩阵为 `72192 x 4225`，约 2.440 GB。SVD、H2 缩放、临时矩阵还会消耗额外内存。

本对照衡量相同稠密求解框架下的空间精度与成本，没有利用 B-spline 的稀疏性，也不是周期矩形上直接 FFT Poisson 求解的计时。不能据此否定专用稀疏样条或结构化 Fourier extension 算法的成本优势。

## 复现

```sh
for family in fourier bspline bspf; do
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python \
    examples/pde/compare_poisson_bases.py --family "$family" --resume
done
MPLCONFIGDIR=/tmp/bspf-mpl python examples/pde/render_poisson_basis_comparison.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python \
  examples/pde/validate_poisson_basis_comparison.py --order 24
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m pytest \
  -q packages/models/tests/test_poisson_basis_comparison.py
```

`--resume` 只复用设置一致且 PDE、H2 诊断均完整的结果。不复用早前采用其他边界采样数、约束空间或求积规则的运行。
修改 MMS 定义或基函数实现后，应不用 `--resume` 重新运行；该选项检查参数，不检查源文件哈希。

额外验证脚本只读取 N=65、cutoff=1e-13 的已保存系数，使用共同 Q24 物理求积计算
L2、梯度、H2 和 Laplacian 相对误差，写入 `refined_validation.json`；它不重新拟合，
也不会改变主图的独立均匀验证点。这项检查不证明连续全空间最优性，但能检查训练点或
某个独立点云上的偶然误差低估。
