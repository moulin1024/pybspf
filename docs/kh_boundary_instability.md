# KH 无缓冲不稳定性：定位到入流端对流离散

本轮在原正式网格 **160×112** 上复现并诊断。结论是：当前 BSPF 一阶微分与强 Dirichlet 速度边界的组合，在入流端附近产生了不稳定的对流模态。缓冲层在此起到压制该数值模态的作用，不是 KH 物理模型本身要求的项。

这已不只是依据动画作出的判断：无缓冲时间推进、半步长复算、完整投影 NS 的线性化谱、无剪切匀速流控制，以及一维导数和边界行替换给出了相互一致的证据。没有修改生产 NS/压力实现，也没有加入壁面梯度补全。

## 复现配置与范围

沿用原 KH 的区域 `[-3,3]×[-1,1]`、ν=0.002、δ=0.12、初扰动 0.03、波长 1.5、固定维持基流体力，以及四边固定 `U0=(tanh(y/δ),0)`。BSPF 参数 q=9、32 基函数、degree=13、Chebyshev 12 模式／16 点窗口保持不变。

原 KH 的密集压力阶段调用 `project_pressure2d(..., completion=False)`，沿用其历史默认的 **两次离散压力精修**。本轮保留这一行为以隔离缓冲项的影响，没有把近期三维“零精修”设置默默移植到旧 KH。这里的迭代特征值分析是诊断工具，不是 NS 时间推进的压力求解算法。

非线性复算每 0.05 时间单位记录一次诊断；最大速度超过 10 或数值有限性／散度检查失败时停止。报告中的 t=2.35 是触发该阈值的采样时刻，不是一个精确计算的数学爆破时间。

## 1. 缩小步长不能消除失稳

| 配置 | 终止时刻 | 最大速度 | 边界条带扰动 RMS | 状态最大散度 | 壁面速度误差 |
|---|---:|---:|---:|---:|---:|
| 无缓冲，dt=0.002 | 2.35，超过阈值 | 15.167 | 1.258 | 9.68e-12 | 0 |
| 无缓冲，dt=0.001 | 2.35，超过阈值 | 14.972 | 1.273 | 8.12e-12 | 0 |
| 仅 x 缓冲，dt=0.002 | 3.00，正常完成 | 1.216 | 0.0146 | 2.88e-12 | 0 |

条带定义为 `|x|>2.4 或 |y|>0.8`；RMS 使用梯形积分权重，并测量相对基流的两个速度分量。

两种无缓冲步长在 T=2 的扰动相对 L2 差异仅为 **8.05e-6**。到快速非线性爆发的末态，差异增加到约 5.3%；这说明末期时间误差也会增大，但不能解释早期就存在的半离散增长模态。

所有已记录区间的阶段压力状态都通过原有检查。失稳末态压力 Schur 最大残差约为 7.8e-9／1.1e-8，状态散度仍约 1e-11。速度可以保持离散无散，同时出现幅度爆发；“Poisson 解准确”和“NS 稳定”是不同要求。

仅 x 缓冲的本次复算只验证到 T=3；原全缓冲算例已运行至 T=6。不能据此宣布 y 缓冲对所有后续非线性状态都不需要。

## 2. 完整 NS 投影之后仍有非物理边界增长模态

用 JAX JVP 得到维持基流附近的 Jacobian 作用，随后用 SciPy ARPACK 求实部最大的六个特征值。未知量为内部两个速度分量，壁面扰动严格为零。每个返回特征对都重新计算 `Jv-λv`，不是仅引用 ARPACK 状态。

| 线性化对象 | 主导特征值 | 边界条带模态能量 | 中心区域模态能量 | 主导特征对相对残差 |
|---|---|---:|---:|---:|
| KH 基流，无缓冲 | 7.7971 ± 34.6119i | 99.8465% | 0.0180% | 1.82e-14 |
| KH 基流，全缓冲 | 1.32433 | 0.2408% | 94.4627% | 3.38e-13 |
| 匀速流 `(1,0)`，无缓冲 | 8.02198 ± 34.8096i | 99.5542% | 0.0775% | 6.42e-13 |

中心区域定义为 `|x|<2, |y|<0.5`。模态能量取内部网格上的 `|u|²+|v|²`；内部均匀积分权重相同，因而此处与加权能量比例一致。

无缓冲 KH 主模态约 **99.79%** 能量在左右边界条带，其中约 **99.69%** 落在入流侧：上半域左端、下半域右端。峰值位于右侧第一内部节点附近。没有剪切的匀速流仍出现类似的快速边界模态，因此不能把它解释为物理 KH 增长。

对无缓冲主模态 λ，RK4 的放大函数为

```
R(z)=1+z+z²/2+z³/6+z⁴/24,  z=dt λ.
```

`log|R(dt λ)|/dt` 在 dt=0.002 与 0.001 时分别为 **7.797099、7.797106**，均非常接近半离散增长率 7.797106。减小步长是在更准确地积分这个不稳定的空间离散算子，不能使其稳定。

加缓冲后的中心增长模态与 KH 增长相符，但本轮没有证明缓冲对物理增长率完全无影响，也未追踪无缓冲谱中的同一中心模态。

## 3. 不需要 NS 非线性或压力，就能复现问题

考虑在相同 x 网格上的一维标量问题：

```
w_t + w_x = ν w_xx,   w(-3)=w(3)=0,   ν=0.002.
```

连续能量恒等式为

```
d/dt [ 1/2 ∫ w² dx ] = -ν ∫ (w_x)² dx ≤ 0.
```

它没有 KH、非线性卷丝、aliasing 或压力求解。取零边界后的一维内部矩阵 `A=-D1_II+νD2_II`，结果如下：

| 对流导数 | 扩散导数 | 最大特征值实部 |
|---|---|---:|
| BSPF D1 | BSPF D2（原配置） | **+10.0670** |
| BSPF D1 | BSPF D1@D1 | +10.1356 |
| BSPF D1 | 二阶中心 FD D2 | +9.4950 |
| 二阶中心 FD D1 | BSPF D2 | **−0.4821** |
| 二阶中心 FD D1 | 二阶中心 FD D2 | −2.8090 |

单独的原 BSPF 扩散矩阵最大实部为 −0.0005483。将 D2 改成 D1 平方也没有消除问题；替换对流导数却可以消除这个一维算例的正实部谱。由此把主要触发因素定位到当前对流导数与边界处理的组合，而非黏性正号错误或 D2/D1² 不一致。

原一维不稳定模态的峰值在 **x=−2.96226**，即 U=+1 时入流端的第一个内部节点，超过 99.999% 的模态能量位于左端条带。

## 4. 进一步定位：入流端前两行

仅替换内部对流矩阵的少数行，其他行和 BSPF D2 均保持不变：

| 一维诊断替换 | 最大实部 |
|---|---:|
| 不替换 | +10.0670 |
| 入流端第一个内部节点改二阶中心 FD | +0.9709 |
| 入流端前两个内部节点改二阶中心 FD | **−0.6180** |
| 出流端前两个内部节点改二阶中心 FD | +10.0737 |
| 出流端前 16 个内部节点改二阶中心 FD | +10.1040 |

这是定位实验，不是已验证的全 NS 修复。尤其两端同时只换两行仍有 +0.0261 的小正实部，说明不能把局部经验补丁直接当作具有一般稳定性保证的边界算法。

这个结果支持优先检查入流侧最靠近端点的高阶微分闭合。尚未单独分离 Chebyshev jet 拟合、全局样条修正和强边界约束各自的贡献；不能据此断言 Chebyshev 拟合本身必然不稳定。

## 5. 缓冲层实际做了什么

原缓冲项在基流附近增加 `-σw`，在压力投影之前作用，改变了空间算子。对一维原算子，`σ=s(x/3)^16` 的结果为：

| s | 最大实部 |
|---|---:|
| 0 | +10.0670 |
| 10 | +3.8941 |
| 20 | −1.3420 |
| 40 | −2.4190 |
| 80 | −3.5840 |

因此原来的 s=80 有明确的数值稳定作用。但这里的一维阈值不是完整非线性 NS 的通用最小缓冲强度。

## 后续方向

应优先构造满足离散分部积分／能量估计的高阶入流边界处理，再验证无剪切控制和 KH。至少要检查齐次边界的标量对流–扩散算子没有正实部谱，并检查完整投影 NS 的边界模态。对流离散、速度边界施加和压力投影的兼容性需要一起考虑，不能只凭微分制造解的高精度选择闭合。

不建议把“加大缓冲、减小 dt、增加压力精修、补全壁面压力梯度”作为对此根因的修复。前者会改变模型；步长和压力精度没有消除空间不稳定的机制；壁面梯度补全只调整内部动量不可见的压力自由度，不能修正本次的对流边界模态。

本轮没有检查强非线性晚期的 aliasing 是否还会构成另一项限制，也没有进行该不稳定谱随网格、q、端点窗口参数变化的完整扫描。

## 文件与复现

- `scratch/diagnose_kh_stability.py`：一维算子、非线性复算、完整 NS 线性化谱。
- `scratch/diagnose_kh_line_closure.py`：对流／扩散及入流／出流边界行替换。
- `scratch/report_kh_stability.py`：只读取结果，生成图和汇总。
- `build/kh_stability/`：JSON、特征向量、速度快照、PNG/PDF；原动画与生产代码未修改。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python3 scratch/diagnose_kh_stability.py --mode operators --nx 160 --ny 112
python3 scratch/diagnose_kh_stability.py --mode evolve --nx 160 --ny 112 --variant none --T 3
python3 scratch/diagnose_kh_stability.py --mode evolve --nx 160 --ny 112 --variant none --dt .001 --T 3
python3 scratch/diagnose_kh_stability.py --mode evolve --nx 160 --ny 112 --variant sponge_x --T 3
python3 scratch/diagnose_kh_stability.py --mode spectrum --nx 160 --ny 112 --variant none
python3 scratch/diagnose_kh_stability.py --mode spectrum --nx 160 --ny 112 --variant sponge
python3 scratch/diagnose_kh_stability.py --mode spectrum --nx 160 --ny 112 --variant uniform
python3 scratch/diagnose_kh_line_closure.py
MPLCONFIGDIR=/tmp/pybspf-mpl python3 scratch/report_kh_stability.py
```

所有三个诊断脚本通过 Ruff。特征对真实残差、步长对照和算子替换是本轮的数值验证；未重新运行与此次无改动的生产代码单元测试。

## 后续实现

新增 `closure="sbp84"` 可选路径，以高阶 SBP、相容扩散和正交直接投影满足半离散能量估计。此分支改变原 BSPF 空间离散，默认 BSPF 保持原行为；详见[实现与验证](kh_energy_stable_closure.md)。

后续一维试验已找到保留原 BSPF 插值空间的稳定方向：采用真实质量矩阵的 Galerkin 弱形式，并解决基函数组装中的相消误差。其解析 PDE 误差可收敛到双精度水平；参见[保留 BSPF 精度的一维能量稳定试验](bspf_weak_advection_diffusion_1d.md)。这项工作尚未接入 NS，先前的 SBP 有限差分分支因精度要求被否决。
