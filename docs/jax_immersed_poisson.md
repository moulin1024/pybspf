# BSPF 光滑场浸没边界 Poisson 原型

实现：`packages/models/src/bspf_models/elliptic/immersed_poisson.py`。问题为

\[
 B=[-1,1]^2,\qquad H=\{((x-.19)/.31)^2+((y+.13)/.23)^2<1\},
 \quad\Omega=B\setminus\overline H,
\]
\[
 -\Delta u=f\quad\text{in }\Omega,\qquad
 u=0\quad\text{on }\partial B,\qquad u=g\quad\text{on }\Gamma=\partial H.
\]

这是准确性优先的**稠密参考原型**。背景矩形取正方形；孔洞是偏心解析椭圆。
可以修改椭圆中心、半轴和背景半宽。尚不支持旋转椭圆、多孔、移动壁面、
一般非齐次外壁或 Navier–Stokes。没有修改原矩形 BSPF 微分/椭圆求解代码。

## 孔内辅助场如何联合求解

在原矩形齐次 Dirichlet BSPF 张量空间中设一个全盒未知场

\[
 U_N(x,y)=\sum_{i,j}c_{ij}\phi_i(x)\phi_j(y),\qquad
 u_N=U_N|_\Omega,\quad \xi_N=U_N|_H.
\]

`u_N` 是物理解，`xi_N` 是孔内辅助场。它们共享系数，因此在界面上不存在
由拼接引入的值/导数跳跃；匹配到原基函数本身允许的光滑阶数。
孔内不施加物理 Poisson 方程，不读取孔内 f、MMS 值或真解法向导数。
辅助场不是流体，绘图时单独标识。不能把“共享光滑表示”等同于解析延拓：
孔内藏有真解奇点时，辅助场必须偏离那个奇异表达式。

令 `L` 为原 BSPF 强形式负 Laplacian 的孔外采样矩阵，`T` 为孔壁值矩阵，
`A_B` 为原矩形弱形式 Poisson 算子。采用

\[
 \min_z\;\|W^{1/2}(L A_B^{-1}z-f)\|_2^2
       +\|S_{3/2}(T A_B^{-1}z-g)\|_2^2,
 \qquad c=A_B^{-1}z.
\]

其中 `S_3/2` 在真实椭圆上的等弧长节点做 FFT，将第 k 模态乘
`(1+k^2)^(3/4)`，并包含周长和正负频率归一化。这与 Dirichlet 椭圆问题的
`L2` 体残差和 `H^(3/2)` 边界迹共同控制 `H2` 误差的思路相符。
连续稳定性估计不自动证明某一组离散采样稳定；必须独立验证。

外矩形零边界由试探空间直接满足。**孔壁 Dirichlet 条件是上述最小二乘中
高精度拟合的约束，不是在有限 N 下用拉格朗日乘子逐点强制为零残差。**
壁面误差作为独立指标报告，不把它隐藏在体误差中。

原矩形逆在一维质量归一化模态中就是
`c[i,j] = z[i,j] / (lambda[i]+lambda[j])`。实际调用原有
`tensor_inverse -> tensor_elliptic_solve`，而非重新实现另一个 Poisson 逆。
它是联合系统的右预条件器；带孔求解整体仍是稠密最小二乘，不能将整个算法
称为一次快速矩形 Poisson 求解。

## 实际复用的矩形代码

- `_stream_line(..., clamped=False, dirichlet=True)`：原 BSPF 空间、一维积分、
  外壁约束、质量/刚度归一化和模态特征值。
- `stream_evaluate_line`：原 MPFR 构造/float64 输出的值、一阶和二阶导数。
- `tensor_product`：指定 Cartesian 网格上的快速张量求值。
- `tensor_elliptic_solve`：原矩形可分离椭圆逆。
- `trace_transform`：前述边界 FFT 离散 Sobolev 范数。

原有 q=9、13 次样条部分、32 个样条基函数均不变。默认端点窗口
`min(N,24)`，Chebyshev 模态 `min(窗口数,20)`；可显式传入旧的 12/12 设置。
这属于原框架已经支持的参数，不是更换近似空间为纯 Fourier。

## 采样与稳定化

1. 矩形规则观测网格约每方向 1.5N 点，包括外盒边缘；只保留孔外点。
   边缘采用半权重。这里的 N 是 BSPF 背景节点数，外壁约束后未知数为 `(N-2)^2`。
2. 在解析孔壁等弧长节点之间错开半步，沿精确法向向流体侧加入三圈 PDE 点，
   距离为 `width * (1e-6, 1/4, 3/4)`，width 不超过观测网格间距和外壁间隙的 1/3。
   这些点填补规则网格与曲壁之间漏检的薄层。
3. 孔壁默认 4N 个等弧长点。边界范数由 FFT 实现，体场仍为矩形 BSPF。
4. 对完整白化采样矩阵做薄 SVD，截断相对奇异值小于 `1e-12` 的方向。
   不形成正规方程。固定几何/网格/参数时只分解一次。
5. 以后每个右端项只做缓存矩阵乘法、对角求逆。指定输出点/网格的
   一维求值因子也缓存；不同 f、g 复用同一计划。

矩形筛点和法向补点定义的是一个加权采样范数，**不是谱精度的 cut-cell 积分**。
孔内外指示函数没有被拿去做 Fourier 微分，因此不会通过那条路径制造 Gibbs
现象；但采样是否充分仍会影响稳定性。`collar=False` 可用于补点消融实验。

## 验证问题与独立性

`examples/pde/immersed_poisson_convergence.py` 使用同一几何、同一算法参数：

- `random4`、`random8`：64 个随机方向、随机相位的平面波，波数上限分别为
  4π、8π，再乘 `(1-x²)(1-y²)` 保证外壁零值。所有 f 均解析计算。
  波谱只是合成湍流风格的 MMS，不是求解湍流动力学。
- `pole`：`u=(1-x²)(1-y²) log(r)`，r 到孔中心的距离。在物理域解析，在孔内
  有对数奇点，因此不存在同一个表达式在整个背景盒上的解析延拓。
  这是对未知孔内延拓能力的独立检验。
- 单元测试另含多项式、实际近壁梯度/Laplacian、几何法向、非方形输出网格、
  原矩形逆一致性、因子复用，以及拒绝孔内 f 请求的回调断言。

MMS 真解只用于生成 f 和壁面 g，并在解出以后评价误差；没有把真解当特解。
独立检查使用错位的 257×257 网格、偏移弧长孔壁点，以及距离孔壁
`1e-2,1e-3,1e-4,1e-6` 的四圈点。另检查外盒边缘的值、梯度和 PDE 残差。
图中的 257×257 是显示/验证采样，不是新增求解自由度。

结果文件为 `build/immersed_poisson/results.json`；图与原始场同目录。

## 使用与复现

```python
import jax
import numpy as np
from bspf_models.elliptic.immersed_poisson import ImmersedPoissonPlan

jax.config.update("jax_enable_x64", True)
plan = ImmersedPoissonPlan(nodes=65)
f = lambda p: 4 - 2*np.sum(p*p, axis=1)
g = lambda p: (1-p[:, 0]**2)*(1-p[:, 1]**2)
solution = plan.solve(f, g)
x = np.linspace(-1, 1, 129)
y = np.linspace(-1, 1, 97)
u, grad, laplacian = solution.grid(x, y)  # shape (97,129); grad has last axis 2
xx, yy = np.meshgrid(x, y)
fluid = plan.hole.level(np.stack((xx, yy), axis=-1)) >= 1
u_physical = np.where(fluid, u, np.nan)
```

返回的 Laplacian 是 **Δu**，方程约定为 **−Δu=f**。
孔内返回值仅是辅助场；用户可以用同一几何掩码隐藏它。

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python examples/pde/immersed_poisson_convergence.py --nodes 17 25 33 49 65 81
MPLCONFIGDIR=/tmp/bspf-mpl python examples/pde/render_immersed_poisson.py
python -m pytest -q packages/models/tests/test_immersed_poisson.py
```

## 成本和结论边界

记 d=(N−2)²，观测数 m=O(d)。联合系统薄 SVD 约 O(md²)，缓存 O(md+d²)，
每右端 O(md+d²)。也就是当前二维稠密参考版的构造约 O(N⁶)、存储/右端约
O(N⁴)，并非原矩形张量求解器的成本。固定几何下 SVD 一次支付；移动孔洞需重建。
一维输出因子可复用，张量网格求值不需要存储完整二维求值矩阵。

解析孔壁是获得快速收敛的有利条件，但不能单独保证指数收敛。原 BSPF 的
固定端点处理阶数、样条光滑性、孔内延拓可逼近性、采样稳定性、SVD 截断和浮点
舍入都会影响最终误差。外矩形角点和不相容数据也可能导致物理解不够光滑。
本原型仅凭所报告的测试区间判断“接近谱精度”，不声称任意数据下严格指数收敛。
下一步的性能工程应围绕该参考解做矩阵自由或边界/孔内低秩消元，不能用尚未
验证的快算法替代当前的精度证据。
