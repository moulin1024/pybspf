# BSPF 压力特征变换的可压缩性实验

实验日期：2026-09-18。结论：目前没有看到“单个快速变换加全局低秩修正”的有效压缩；在三角变换系数空间做层次非对角低秩压缩有收益，值得进一步实现快速直接应用，但尚无运行时间或三维精度收益的验证。

## 对象与可复现方法

直接调用 `jax/src/bspf_jax/pressure.py` 的 `_make_line`，读取实际 JAX float64 生成的特征向量 V、逆矩阵 Vi 和特征值。使用 CPU，均匀端点网格 [0,1]，N=64、128、256、512，内部维度 m=N-2，q=9、样条数32、degree=13。Taylor 使用14个端点拟合样本；Chebyshev 使用16个样本、12个模态、正则化1e-12，与当前 KH 设置一致。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=jax/src \
MPLCONFIGDIR=/tmp/pybspf-mpl \
python3 scratch/analyze_pressure_transforms.py
```

输出位于 `build/pressure_transform_analysis/`：`results.json`、`compressibility.png/pdf`，以及8组包含 V、Vi、特征值、独立重建的消元算子 A 的 NPZ。实验脚本只做分析，未修改生产求解器。SVD、匹配与诊断用 SciPy/NumPy；数值对象来自 JAX。

## 1. 整体低秩与快速基加低秩

测试正交归一化 DCT-I、DCT-II、DST-I 和实 Fourier 基，均为内部 m 点上的方阵。用最大重叠的线性指派匹配模态，允许列置换以及复数对角缩放（包含符号/相位），避免把模态顺序与符号差异误判成不可压缩。

设 T 为快速正交基，P 为模态置换矩阵，计算

\[
C=T^*VP,\qquad B=P^TV^{-1}T.
\]

分别对 C、B 去掉其最优对角部分后做 SVD。数值秩定义为最小 r，使截断尾部 Frobenius 范数不超过整个变换 Frobenius 范数的指定比例。V 和 Vi 本身也做相同的整体低秩测试。

在 1e-10 相对误差下，**全部8种配置的 V、Vi 本身，以及全部4种匹配快速基下的非对角修正，均需要满秩 m**：62、126、254、510。在 N=512、Chebyshev、DCT-II 下，放宽到1e-6，V 的修正仍需要508阶。

这排除了本实验所测的简单全局低秩模型，不是对所有可能快速基、模态子空间旋转或结构化分解的不可能性证明。近零模态的特征向量可随后端旋转，未对其进行专门的最优旋转搜索。

V 的2范数条件数：Taylor 为3.18–5.49，Chebyshev 为12.41–18.21。这里的整体不可压缩主要不是极端病态导致的。

## 2. 频率系数空间的分块压缩

对 C 和 B 递归二分：对角块继续分解，非对角兄弟块用截断 SVD，叶块最大16。每个非对角块满足局部相对 Frobenius 容差；如果低秩因子比原块更大，就保存原块。这是 HODLR 形式的诊断重建，不是已实现的快速矩阵乘法。

下表选择每个配置在1e-10容差下 V、Vi 合计因子最少的基。比例是因子标量数量/原稠密矩阵标量数量，不含元数据、快速变换和后续零空间修正开销。

| N | 端点处理 | 基 | V 存储比例 | Vi 存储比例 |
|---|---|---|---:|---:|
| 64 | Taylor | DCT-I | 100.0% | 100.0% |
| 64 | Chebyshev | DCT-I | 100.0% | 100.0% |
| 128 | Taylor | DST-I | 84.9% | 84.9% |
| 128 | Chebyshev | DCT-II | 85.7% | 85.7% |
| 256 | Taylor | DCT-II | 62.6% | 62.4% |
| 256 | Chebyshev | DCT-II | 64.4% | 63.6% |
| 512 | Taylor | DCT-II | 44.6% | 44.3% |
| 512 | Chebyshev | DCT-II | 47.4% | 46.4% |

N=512 的 Chebyshev 情形，顶层255×255非对角块的最大秩分别为38和36。直接对物理空间中的 V、Vi 做同样的 HODLR 压缩效果差：V 在 N≤256 时无存储收益，在 N=512 时仍需98.5%存储。

提高分块精度到1e-12，N=512 Chebyshev 的 V、Vi 分别仍可用53.1%、52.2%的因子存储量表示。不能把这些比例换算成运行时间加速：小块调度、FFT/DCT、批处理/GPU利用率都尚未测量。

## 3. 不使用迭代精修的直接解验证

从 JAX 的 FFT 乘子、低秩导数修正和端点消元数据独立重建 A，而不是用 V Lambda Vi 重建。8个配置的特征分解相对残差为2.8e-15–7.4e-15。

构造二维内部 Kronecker 和及原有四个零模态的 -10 lift。用两个已知压力生成右端：固定随机种子的网格白噪声、以及平滑函数 exp(x+0.5y)+sin(3pi x)cos(2pi y)。使用压缩的 V 和 Vi 直接求解一次，检查相对解误差和原始消元算子的相对残差。**没有外层迭代，也没有迭代精修。** 这是内部 lifted 系统的测试，不是完整壁面补全、三维 NS 或全部可能右端的误差保证。

N=512，Chebyshev：

| 变换处理 | 随机压力相对解误差 | 平滑压力相对残差 |
|---|---:|---:|
| 原始稠密变换 | 2.39e-11 | 5.78e-11 |
| 分块容差1e-10 | 1.71e-8 | 7.03e-9 |
| 分块容差1e-12 | 5.05e-10 | 8.90e-11 |
| 分块容差1e-12，额外保护零空间 | 5.00e-10 | 6.26e-11 |

零空间保护是固定的低秩代数修正：精确保留 V 的前两列和 Vi 的前两行，并纠正剩余变换对这些左右零空间的泄漏；它不是迭代。它能改善平滑场的残差，但不能消除全部低频误差放大，随机压力的解误差仍比稠密基准高。

注意：1e-10 是分块矩阵近似容差，不能直接当成压力解或残差容差。平滑函数的相对残差在原始稠密解中也受到微分算子条件数和浮点消去的影响；表格保留基准以区分新增压缩误差。

## 建议

1. 不优先实现单个全局低秩补丁；当前结果没有支持它。
2. 如继续实现压缩直接法，优先采用 `快速 DCT + 系数矩阵 HODLR`，V 和 Vi 都必须处理。
3. 从1e-12分块容差开始，显式保留零模态，并进一步研究低频模态保护或按求解敏感度分配误差，而不是只控制矩阵 Frobenius 误差。
4. 实现实际因子应用后，再对更大网格测量秩增长、直接求解精度与耗时。只有秩增长受控，才有理由讨论接近 O(N^3 log N) 或带额外对数因子的三维复杂度；当前四个规模不足以证明渐近复杂度。

本实验未实现 butterfly 分解，也未证明该结构不存在。没有声称已经把原有直接法加速到某个倍数。
