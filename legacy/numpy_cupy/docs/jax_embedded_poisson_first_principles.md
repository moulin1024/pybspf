# 当前 BSPF 下嵌入域 Poisson 高精度算法的数学设计

本文是推导和下一版设计，未实现本文提出的新离散。已有实验仍保留。
按用户最新限定，下一版仅考虑**光滑凸的闭合 B-spline 区域**。
下文一般稳定性推导仍适用；第9节给出凸性提供的更强结论和当前优先方案。
问题为 −Δu=f 于 Ω，u=g 于 Γ=∂Ω，Ω 紧包含于矩形 B。
假设 Γ 正则、简单、无自交、至少 C^{1,1}；当前两条 C2 三次 B-spline 满足
所需局部光滑性。f∈L2(Ω)，g∈H^{3/2}(Γ)。下文先将长度无量纲化。

## 1. 代码实际代表的空间

`mp_trial_values` 中的一维原始行向量可写成

    Φ(x) = [F(x),0] + (S(x) − F(x) S_X) P.

F 为 Fourier cardinal 插值行，S 为32个13次 B-spline，S_X 为其在周期
采样点上的值，P 是端点 jet 投影器。端点使用 q=9、Chebyshev 估计，
MPFR 在构造和求值时处理 spline/Fourier 相消，最终矩阵为 float64。
这不是 Fourier 空间与32个任意独立样条系数的直接和：系数通过 P 联系。

`_stream_line` 通过质量 QR、可选边界零空间和刚度特征分解得到 ψ_i。
二维 V_N=span{ψ_i(x)ψ_j(y)}。无约束每方向N维，齐次 Dirichlet
每方向通常N−2维（N=49时二维2209维）。域内使用 V_N|Ω。
对于严格内嵌域，外盒齐次条件并非物理条件；其影响属于扩展空间的选择。
纯可逆基变换不改变空间，端点参数、模式截断和外盒边界零空间会改变空间。

矩形上质量近似I，刚度近似对角K，但限制到 Ω 后质量、刚度一般都不对角。
其不对角不是“微分失效”，而是积分域改变。应直接在物理点评价基函数及
其解析导数，不再引入低阶重建。

## 2. 从误差方程而非经验惩罚出发

任意 v∈H2(Ω)，定义 e=v−u，r=−Δv−f，b=v|Γ−g。
取有界迹提升 L:H^{3/2}(Γ)→H2(Ω)，令 w=e−Lb，则 w|Γ=0，

    −Δw = r + ΔLb.

零 Dirichlet Poisson 的 H2 正则性及提升有界性给出

    ||e||H2 ≤ CΩ (||r||L2 + ||b||H^{3/2}).                 (1)

反向估计由 Δ 和迹算子有界得到。因此

    ||v||graph² = ||Δv||L2² + ||v|Γ||H^{3/2}²

与 H2(Ω) 范数等价。常数依赖几何，包括狭窄通道；不要求星形，但不能
假定其对任意严重退化的几何一致。H2 控制域内梯度和 Hessian 的 L2 误差，
不直接保证梯度的点态最大误差；后者需更强正则性与相应范数。

若只关心能量误差，可以使用 H^{-1} 域内残差及 H^{1/2} 边界残差。
这里选择H2，因为目前目标明确包括二阶微分精度。

反例解释普通边界L2的不足：半平面上的调和误差
e(s,r)=a exp(i k s) exp(−|k|r)，k≠0，有 Δe=0；边界L2量级为a，
而每周期归一化后的H2量级为 a|k|^{3/2}。高频边界误差可隐藏在很小的
边界值误差中，并产生较大的导数误差。固定常数beta乘边界L2并不提供
与分辨率无关的H2稳定性；在有限维空间可通过逆不等式选取N相关惩罚，
但会引入尺度/条件数问题。它并非完全不能收敛。

## 3. 首选的一致连续最小二乘问题

保持现有 BSPF 空间，定义

    u_N = argmin_(v∈V_N|Ω) J(v),
    J(v)=||−Δv−f||L2² + ||v|Γ−g||H^{3/2}².              (2)

由(1)、最小化性质和算子有界性，

    ||u−u_N||H2 ≤ C inf_(v∈V_N|Ω) ||u−v||H2.           (3)

这是连续、精确算术下的准最优结论，不是对当前采样代码已经证明的定理。
不需要给Dirichlet问题额外指定未知Neumann条件，也不需要要求解满足某个
近似外推关系。真实边界上的法向导数由解决定。

## 4. 如何离散 H^{3/2} 边界范数

令s为弧长，周长L，b(s)=Σ b_m exp(i 2πms/L)。采用周期弧长范数

    ||b||H^{3/2}² = L Σ_m (1+(2πm/L)²)^{3/2}|b_m|².

因此最小二乘矩阵的边界行先做弧长 Fourier 分析，再乘
(1+k_m²)^{3/4}。频率不是原始样条参数t的均匀FFT频率。
这是边界上的一维范数表示，不改变体场使用BSPF这一点。

也可在连续周期边界样条空间中组装弧长质量MΓ、刚度KΓ，求
KΓ z=μ MΓ z，在质量正交坐标中乘(1+μ)^{3/4}。质量归一化与系数/采样
投影都必须一致；不是直接对不对称M^{-1}K逐元素取幂。

解析曲线直接提供 ds/dt=|C'|、τ=C'/|C'|、n=(y',−x')/|C'|，
及 ∂s(v|Γ)=τ·∇v。它们用于弧长采样、精确迹、切向解析导数与积分。
不需要用差分法向。分数阶范数须解析足够边界模态，不能先低通滤掉
高频残差后再宣称误差小；加密边界积分/模态数并检查尾部能量。

Γ只有C2，不意味着一般解可无限光滑或指数收敛。但当前MMS是平面上的
解析函数，有限几何光滑性也不能被用来笼统解释这些MMS的误差平台。

## 5. 分清最佳逼近、离散稳定性和正则化

第一项必要诊断是

    ε_app(N)=inf_(v∈V_N|Ω)||u_MMS−v||H2.

可用MMS值、梯度和完整Hessian作独立最小二乘诊断；这些真实导数不能
进入正式PDE解算器。此前仅拟合值后测Laplacian误差，并不等于H2最佳
逼近误差，不能据此断言空间的二阶精度下限。

对采样算子A_h，还应检查存在不随网格退化的 c_s,C_s，使

    c_s ||v||H2² ≤ ||A_h v||² ≤ C_s ||v||H2²            (4)

在实际保留的试验空间成立。完整误差结论还需控制数据/最佳逼近残差的
积分误差；仅(4)对齐次空间成立还不充分。可用独立加密积分构造参考H2
Gram矩阵，并检查A_h*A_h相对该Gram矩阵的广义特征值。参考矩阵也有
数值误差，近秩亏部分不能盲目求逆，要限定可可靠表示的子空间并报告。

体积分沿真实样条切片，分段于几何结点、切线变化及背景样条结点；
边界按弧长分辨实际迹空间。加密应关注这些算子范数和独立残差，不只
检查同一组训练点。固定每段6或12点不是随N增长都成立的精度保证。

## 6. 系数条件数与物理稳定性不是同一件事

V_N在B上独立，限制到Ω后可能近相关。外部很大、内部很小的方向会造成
小奇异值，并不必然对应大的物理误差。反之，按域内L2质量直接截断，
可能删去对边界或导数有意义的方向。截断须针对完整物理观测算子。

可先用背景盒上的实际H2 Gram矩阵G_B规定系数尺度，再令c=R^{-1}a，
R*R=G_B。在一维质量I、刚度K、二阶导数Gram J的张量基中：

    G_B=I + Kx⊗I + I⊗Ky
          + Jx⊗I + 2Kx⊗Ky + I⊗Jy.                    (5)

这里使用Frobenius Hessian范数，所以混合项系数为2。
当前 line.bending 对应J；一般J≠K²，因为离散弱算子平方不等于真实二阶
导数的Gram矩阵。尤其有人工齐次Dirichlet空间时，更不能直接作此等同。
(I+K)^2只能作为需验证谱等价性的候选预条件器。

在A=A_h R^{-1}上做QR/SVD，避免形成正规方程用于解算。G_B定义了矩形
延拓的大小，但最终误差用Ω上的物理范数判断，不要求外部延拓唯一。
数学诊断可用Ω的H2 Gram白化，实际实现需避免近相关方向导致的巨大相消。

对绝对阈值τ的TSVD，精确算术下任意候选a_*满足

    ||A a_τ−d|| ≤ ||A a_*−d|| + τ||a_*||.              (6)

证明：被删除的左奇异向量方向上，A的范数≤τ；将数据写成
A a_*+(d−A a_*)并用正交投影收缩性即可。结合(1)(4)，获得设计性的误差预算

    物理解误差 ≲ 最佳H2逼近误差
                 + 采样/积分误差
                 + τ·可用表示的系数范数
                 + 矩阵求值与浮点解算误差.

相对截断阈值需乘σ_max才是这里的τ。不能将rcond=1e-14等同于解误差1e-14。
舍入误差会涉及矩阵误差乘系数范数；MPFR组装不能保证float64运行中的
任意病态组合仍准确。应报告系数范数和精度敏感性。

## 7. 延拓为何可能有偏，以及应放在哪里

若额外最小化 J(v)+beta²||C_ext v||²，候选解误差估计中会出现
beta||C_ext v_*||。即使v_*已经很接近真实解，近似延拓关系一般也不
精确为零。提高beta会改变离散目标，可解释已观察到的解误差下降而PDE
残差上升。除非证明一致性误差随N足够快衰减，否则不是无害的稳定化。

更干净的原则是：延拓用于构造表示、选择近似外域自由度和预条件；其偏差
必须低于物理误差预算。可用约束范数最小化：

    min ||v||H2(B), subject to ||A_h v−d||≤δ.

δ须来自可达逼近精度和采样/数据误差，而不是任意强行设成机器精度。
这仍可能引入正则化偏差，但不会默默牺牲已指定的物理残差容差。
对严格内嵌C^{1,1}域，有有界H2延拓并可在外盒边缘平滑截断；因此外盒
齐次条件在连续层面不是障碍。固定带宽BSPF能否以小范数表示该延拓，
仍是必须测量的逼近问题。

## 8. 接下来的算法应按这个顺序设计

1. 固定同一几何、背景盒和BSPF空间，测H2最佳逼近随N的变化，同时做
   矩形参考，排除端点处理和有限分辨率本身的瓶颈。不能用不同外盒/空间
   的矩形机器精度结果作为直接标准。
2. 实现(2)的H^{3/2}边界迹范数，先以充分加密积分、QR/SVD和独立误差
   验证逼近(3)的行为，不加入局部外推惩罚。
3. 用(4)检查实际保留空间的采样稳定性；同时检查边界模态尾部、积分
   加密、SVD阈值及系数范数敏感性。
4. 明确误差预算后，再将矩形张量椭圆逆用于预条件/分块特解。
   域限制破坏可分离性，矩形逆不是嵌入域物理算子的精确逆。
5. 若H2最佳逼近本身不好，增加N、调整端点空间或引入边界适应富集。
   此时才有数学依据考虑特解+调和修正或局部patch；边界积分是可选的
   表示方法，不是从失败实验直接推出的唯一方案。

以上给出的是可检验的数学设计，而不是已经保证当前N=49能达到机器精度。
高精度必须同时满足逼近性、稳定采样、一致离散和有限精度可实现性。

## 9. 限定凸域后的直接推导与优先方案

令正曲率约定为凸曲线κ≥0（逆时针切向τ满足∂sτ=−κn）。对
v∈H2(Ω)∩H1_0(Ω)，先对足够光滑v用散度定理，再用适当密度延拓：

    div[(Δv)∇v−D²v∇v] = (Δv)²−|D²v|_F².

边界v=0意味着∇v=(∂n v)n，且沿曲线二次微分得到
τᵀD²vτ=κ∂n v。因此

    ∫Ω[(Δv)²−|D²v|_F²] = ∫Γ κ(∂n v)² ≥ 0,
    ||D²v||L2 ≤ ||Δv||L2.                              (7)

这是Miranda–Talenti不等式。结合Poincaré不等式和
||∇v||²=−(v,Δv)，得||v||H2≤CΩ||Δv||L2。
因此**只要真实边界条件严格满足，控制Poisson残差就直接控制全部二阶
导数的L2误差**。不需要单独匹配真实法向导数。

非零边界误差仍需迹提升，故(1)的H^{3/2}项不能因凸性而删掉。
边界上若只有有限点值为零，不满足(7)使用的连续零迹前提。
解析边界和精确法向不自动等于强制边界条件被精确满足。

在保持现有张量BSPF空间不变的前提下，优先实现(2)，用弧长H^{3/2}
边界范数建立稳定性，而不是先构造全新全局定义函数或做奇异中心的极坐标映射。
若以后能构造光滑定义函数ρ（Γ上为零、Ω内正、边界梯度不消失），可以
研究u_N=G+ρw_N，其中G是仅由g构造的可靠提升。但这会改变试验空间，
且算子变成−Δ(ρw)=−ρΔw−2∇ρ·∇w−(Δρ)w，需要重新验证逼近性。
一般凸样条的ρ并非已有代码免费提供；全域最近距离也可能在中轴不光滑。

凸域第一阶段的判断标准应是：固定N，新的Poisson解误差是否跟踪独立
H2最佳逼近诊断，而不是只与上一种惩罚算法相比。若两者同阶且稳定采样
验证通过，边界离散已经接近该空间可达到的水平；否则继续定位迹采样、
范数权重、正则化或浮点相消，不能靠任意增加约束遮盖问题。

参考：Gallistl 的[综述性学位论文](https://users.fmi.uni-jena.de/~gallistl/publikationen/pdf/2018-g-habil.pdf)
讨论凸域零迹函数的Miranda–Talenti估计。这里给出的二维曲率公式用于直接说明
凸性在本问题中的作用。
