# 工程导向算例：拉长托卡马克的被动壁稳定化

默认求解器现已采用 [统一 BSPF 空间离散](jax_tokamak_all_bspf.md)。
本文“当前结果”表保留原 BSPF/FEM 对照数据；新数据输出在 `build/tokamak_confined_bspf/`。
以 `--vacuum-method fem` 可显式选择旧后端。

目标是研究**相同线圈与等离子体平衡，导电壁的位置如何改变垂直稳定性**。
这是可用于方法验证和参数扫描的约束问题，不是燃烧等离子体或反应堆设计。
实际装置确实采用被动稳定结构和主动垂直控制：参见
[IAEA 关于托卡马克壁面与被动稳定板的研究](https://conferences.iaea.org/event/214/contributions/17285/)
及 [ITER 垂直稳定线圈](https://www.iter.org/node/20687/design-iters-vessel-coils-converging)。

构型保留固定的12个轴对称线圈、自洽闭合磁面和约1.63的拉长比。
围绕参考点 `(R,Z)=(2,0)` 将等离子体边界按1.2倍缩放得到静止导电壁，
两者之间是真空。这里的20%是各射线方向的半径比例，**不是处处相同的法向间隙**。
初始基态无平衡面电流；壁面对扰动保持磁通冻结。

原电流剖面比较尖峰化；通过调节常数环向场参数 F，使轴上安全因子达到1.3，
并积分每个磁面上的 `q=F/(2*pi) integral dl/(R |grad psi|)` 得到实际剖面。
不预设 q95，也不把 q>1 当作所有三维模稳定的证明。
本算例更接近低 beta、高边缘 q 的基础约束/启动研究，而非优化后的高性能放电。

给定平均垂直位移 `0.002*a`、零初速度，推进所有离散位移和速度自由度。
位移通过质量投影初始化，不把后续运动限制为刚体。理想无耗散模型应产生
有界振荡，而非自行衰减到静止。同一扰动也施加到远矩形壁对照；对照位移
达到 `0.02*a` 后停止，以免把线性模型外推到大位移。

```bash
PYTHONPATH=jax/src OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python examples/pde/tokamak_confined.py
PYTHONPATH=jax/src OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python examples/pde/render_tokamak_confined.py
```

输出 `build/tokamak_confined/summary.json` 包含壁面扫描、稳定性谱、能量漂移、
最小壁间隙、最大位移、beta 和 q95；`q_profile.json` 保存安全因子剖面。
绘图显示平衡磁面、运动边界、导电壁及稳定/不稳定对照，全部几何位移按真实比例。

## 当前结果

默认 n=49、modes=14、真空256角点/48层时：

| 量 | 结果 |
|---|---:|
| 拉长比 | 1.6343 |
| 轴上安全因子 / q95 | 1.30 / 8.476 |
| 体积平均 beta（2〈p〉/〈B²〉） | 0.1756% |
| 平均垂直初始位移 | 0.2% a |
| T=100 内最大平均垂直位移 | 0.2% a |
| T=100 内最大边界位移 | 1.553% a |
| 记录时刻的最小壁间隙 | 0.07153（归一化长度） |
| 相对总能量漂移 | 4.85e-13 |
| 中点轨迹与独立模态解的相对差，dt=0.01 | 0.0815% |
| 远矩形壁的增长率 | 0.16073 |

贴近壁构型在解析的垂直模空间中没有增长模，但有接近零频的中性方向，
不能据此宣称存在统一的正稳定裕量。modes=12、14、16均未发现增长模；
占主导的垂直振荡频率平方从modes=14到16仍变化约2.3%，频率尚需进一步收敛。
壁比例1.1、1.2、1.3均能在本模型中被动稳定；壁远离时恢复作用减弱。

一种可选的量纲映射为 `L_unit=1 m, B_unit=0.5 T`，于是磁轴大半径约2.27 m，
小半径约0.541 m、轴处环向场约2.64 T、等离子体电流约0.398 MA。
这些是人为选定的尺度，用于让该基准具有具体的装置量级；并非某实际装置的重建。
时间单位还需要指定质量密度，当前结果中的时间保持归一化。

当前结论仅覆盖所解析的**轴对称垂直奇偶分支**。理想导体壁是被动稳定效果的
理想极限；真实有限电阻壁会有磁通扩散，可能需要反馈控制。
未包含 X 点、偏滤器、热输运、粒子损失、n≠0 模或聚变功率。
要研究真实装置，应引入实际平衡、线圈、电路和壁电阻，再拓展稳定性分支。
