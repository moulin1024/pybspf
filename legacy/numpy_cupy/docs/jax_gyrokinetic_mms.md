# 五维非线性静电 slab 的解析制造解（MMS）

本验证针对 `gyrokinetic_slab.py` 中的周期 δf 模型，空间域为 [0,2π)³。
解析参考与源项实现在 `jax/src/bspf_jax/gyrokinetic_mms.py`；
运行 `examples/pde/validate_slab_mms.py` 可重现时间、空间和速度积分扫描。

## 制造解与解析场闭合

定义两个方向不同的传播相位

\[
\theta_1=x+z-0.9t,\qquad \theta_2=2y-z+0.7t,
\]

以及具有非多项式速度依赖的函数

\[
H_1=e^{-0.4v^2-0.5\mu}(1+0.2v),\qquad
H_2=e^{-0.7v^2-1.2\mu}(1-0.15v).
\]

时间幅值为 A=0.03[1+0.2sin(0.8t)]，B=0.025[1+0.15cos(0.6t)]。
取 0≤r<1，定义解析周期函数

\[
C_r(\theta)=\Re\frac{e^{i\theta}}{1-re^{i\theta}}
 =\sum_{n=1}^{\infty}r^{n-1}\cos(n\theta),\quad
S_r(\theta)=\Im\frac{e^{i\theta}}{1-re^{i\theta}}
 =\sum_{n=1}^{\infty}r^{n-1}\sin(n\theta).
\]

制造分布为

\[
g_*=A(t)H_1 C_r(\theta_1)+B(t)H_2 S_r(\theta_2).
\]

r=0 是两个有限 Fourier 模，适合隔离时间和速度积分误差；
r=0.3 具有无限谐波，用于空间收敛，避免有限模被精确表示后误差直接归零。

以平衡权 exp(-v²/2)/sqrt(2π) × exp(-μ) 积分，利用

\[
\langle e^{-av^2}(1+dv)\rangle_v=(1+2a)^{-1/2},\quad
\int_0^\infty e^{-(1+s)\mu}J_0(\sqrt{2b\mu})\,d\mu
 =\frac{e^{-b/[2(1+s)]}}{1+s},
\]

可得每个谐波的**连续解析场**系数

\[
b_{i,n}=(n k_{\perp,i}\rho)^2,\quad
D_{i,n}=\tau+1-I_0(b_{i,n})e^{-b_{i,n}},\quad
c_{i,n}=\frac{r^{n-1}e^{-b_{i,n}/[2(1+s_i)]}}
 {D_{i,n}(1+s_i)\sqrt{1+2a_i}},
\]

其中 kperp,1=1、kperp,2=2，(a1,s1)=(0.4,0.5)、(a2,s2)=(0.7,1.2)。
于是

\[
\phi_*=A\sum_n c_{1,n}\cos(n\theta_1)
       +B\sum_n c_{2,n}\sin(n\theta_2).
\]

回旋平均势 ψ*=Jφ* 的每项再乘 J0(n kperp,i ρ sqrt(2μ))。
默认 ρ=0.8、τ=1。场系数具有额外的 exp(-constant×n²) 衰减；
实现保留 32 个场谐波，并测试 16 与 32 项的一致性。
分布 C、S 本身直接使用有理式，不截断其解析谐波。
这些公式不依赖数值速度积分，也不需要给准中性方程额外加源。

## 独立推导的非零制造源

求解带给定源的方程

\[
\partial_tg+v\partial_z(g+\psi)+\{\psi,g\}_{xy}=S_*.
\]

将 ψ* 按两个相位拆为 ψ1+ψ2，撇号表示对各自相位求导，则

\[
\begin{aligned}
g_{*,t}&=A'H_1 C_r-0.9AH_1 C_r'
          +B'H_2 S_r+0.7BH_2 S_r',\\
g_{*,z}&=AH_1 C_r'-BH_2 S_r',\\
\psi_{*,z}&=\psi_1'-\psi_2',\\
\{\psi_*,g_*\}&=2(\psi_1'BH_2S_r'-\psi_2'AH_1C_r'),\\
S_*&=g_{*,t}+v(g_{*,z}+\psi_{*,z})+\{\psi_*,g_*\}.
\end{aligned}
\]

平行项、时间导数、FLR 及非线性括号均非零。两个模具有不同 kperp、
不同速度依赖和不同频率，排除了 g 与 ψ 成比例导致括号消失的退化情形。

源项代码使用以上解析导数，没有调用离散 RHS、数值场求解、FFT、
数值微分或自动微分。测试另用 JAX JVP 核对手工导数。
数值推进每个 RK4 子阶段在正确时刻计算 S*，再投影到保留模。

## 带源项的粒子与自由能收支

空间平均 δN*=0。定义

\[
K_i=\frac{(1+4a_i)^{-1/2}+d_i^2(1+4a_i)^{-3/2}}{1+2s_i},\qquad
Q_i=\frac{K_i}{1-r^2}+\sum_n D_{i,n}c_{i,n}^2.
\]

由不同空间模的正交性，连续解析自由能及其源项功率为

\[
W_*(t)=\frac{A^2Q_1+B^2Q_2}{4},\qquad
P_*(t)=\frac{AA'Q_1+BB'Q_2}{2}.
\]

因此此处 W 不应保持常数。正确检查是

\[
N(t)-N(0)-\int_0^t\langle S_*\rangle\,dt=0,\quad
W(t)-W(0)-\int_0^t\langle(g+\mathcal J\phi)S_*\rangle\,dt=0.
\]

代码用与分布更新相同的 RK4 阶段累计两项源收支，并另外比较 W* 与解析累计功。
没有事后修正质量、能量或解的数值。

## 收敛检查的含义

- 时间：r=0，固定足够高的速度积分，演化到 T=0.4，对连续解析 g*、φ* 计算误差。
  g 使用体积平均、Maxwell 加权 L2 范数，φ 使用空间 RMS。
- 速度：r=0，在 t=0.17 分别扫描 Hermite / Laguerre 节点数，比较数值自洽场与解析 φ*。
  这是真正的连续积分参考，未用同一离散积分构造源项或参考场。
- 空间：r=0.3，固定 24×40 速度积分，扫描 N³ 网格，测量节点谱投影误差及
  `RHS(P g*) + P S* - P ∂t g*` 的加权范数。这里 P 是生产求解器的去混叠谱投影。
  它验证空间半离散一致性；不是完整的时间演化网格收敛扫描，也不是统一验证节点上的
  连续空间 L2 误差。源与初值在各网格采样后投影产生的混叠也包含在该检查中。

空间加密时必须充分解析高 kperp 的 Bessel 速度积分。最初使用 16×16 积分时，
N=25 的场误差被高波数 μ 积分误差污染；提高至 24×40 后消除了这一污染。
这也说明空间与速度积分不能只各自用一个小分辨率就宣称独立收敛。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=jax/src \
  python examples/pde/validate_slab_mms.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=jax/src \
  PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest \
  jax/tests/test_gyrokinetic_mms.py jax/tests/test_gyrokinetic_slab.py -q
```

输出：`build/gyrokinetic_mms/report.json`、`convergence.png`。
MMS 验证方程实现与数值一致性；真实无源问题的 Landau 阻尼和非线性谱仍需独立物理基准。

## 实测结果（2026-09-21）

8 项相关测试全部通过，验证脚本所有断言通过。
时间扫描采用 7³ 空间网格、64×40 速度积分，T=0.4：

| dt | 加权分布 L2 误差 | 电势 RMS 误差 | 相对自由能源收支误差 |
|---:|---:|---:|---:|
| 0.04 | 2.903e-10 | 3.142e-11 | 8.665e-11 |
| 0.02 | 1.815e-11 | 2.050e-12 | 2.708e-12 |
| 0.01 | 1.135e-12 | 1.304e-13 | 8.530e-14 |

相邻加密的分布误差阶均约为 4；最细步长的相对解析 W* 误差为 1.549e-11，
累计源功与解析 W*(T)-W*(0) 的绝对差为 2.245e-15。
粒子收支误差约 1.3e-18。

| 每方向空间点数 | 节点投影误差 | 半离散强迫方程残差 | 电势 RMS 误差 |
|---:|---:|---:|---:|
| 7 | 2.730e-3 | 4.831e-4 | 1.259e-4 |
| 13 | 7.536e-4 | 7.377e-6 | 1.506e-6 |
| 19 | 2.242e-4 | 3.391e-7 | 7.527e-9 |
| 25 | 6.721e-5 | 3.818e-8 | 1.203e-11 |

较大的分布投影误差来自无限谐波谱尾部；场积分对这些高谐波有很强的 FLR 平滑，
所以电势误差可以比完整分布误差小很多，不能只看电势就宣称分布充分收敛。

Hermite 从 4 加到 32 点时，电势 RMS 误差从 9.228e-5 降至 1.041e-15；
Laguerre 从 2 加到 24 点时，从 8.067e-4 降至 6.083e-17。
进一步加密后误差在浮点舍入平台附近波动，不要求继续严格单调下降。

## 扩展至 65³：完整速度节点上的分块半离散验证

`examples/pde/validate_slab_mms_large.py` 将空间扫描扩展到 25³、33³、49³、65³。
它保留所有速度积分节点，并逐磁矩块调用与 `slab_gk_rhs` 相同的生产非线性内核
`slab_gk_rhs_with_field_hat`。全局电势先由完整速度积分得到，再供每个块使用；
不能把各速度块各自求出的电势当作全局电势。

制造解的分离形式允许先做离散速度加权收缩、再 FFT；这与先 FFT 再收缩等价。
这里没有用连续解析电势替代数值电势，也没有以解析谱尾代替完整算子检查。
所有 v、μ 节点均参与投影误差和非线性方程残差的积分。
测试用随机分布核对了分块与完整 RHS，并核对分块 MMS 与原有完整数组计算；
包括不能整除磁矩节点数的尾块。新增检查连同已有回归共 10 项通过。

每个 N 在单独进程中运行，记录进程峰值 RSS 与总耗时，包含计划构建和 JIT 编译。
这是一张制造解在 t=0.17 的半离散检查，不是 65³ 的时间推进性能基准。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=jax/src \
  python examples/pde/validate_slab_mms_large.py \
  --sizes 25 33 49 65 --n-v 24 --n-mu 96 --method direct --v-block 24 \
  --out build/gyrokinetic_mms/spatial65_refined
```

这一轮采用 N_v=24、N_mu=96、磁矩块大小为 1。`--n-v`、`--n-mu` 可用于验证速度积分平台。
原先 40 个磁矩节点的结果保留在 `build/gyrokinetic_mms/spatial65.json`，
96 节点的结果位于 `build/gyrokinetic_mms/spatial65_refined/spatial65.json`。

40 节点在 N=65 时给出电势误差 1.027e-8、方程残差 1.684e-8，较 N=33 反而变大。
这是高波数 Bessel 积分分辨不足；投影误差仍与解析谱尾吻合，不能据此判断场闭合也正确。
因此扩展验证还必须提高磁矩积分分辨率。

采用 24×96 速度积分的扩展结果：

| 25 | 6.721e-5 | 3.818e-8 | 1.203e-11 | 3.91 | 0.450 |
| 33 | 2.016e-5 | 2.812e-10 | 1.527e-12 | 7.06 | 0.648 |

## 17³ 至 129³：可分离 MMS 的等价算子验证

新增扫描 N=17、33、49、65、81、97、113、129，使用 N_v=40、N_mu=192。
在 N=129 上，96 个磁矩节点的场积分误差约为 5.4e-12；128 和 160 个节点
仍会留下明显的积分误差。提高到 192 后，连续解析电势对照误差约 9e-17，
再提高到 224 为约 6e-17，已在浮点误差范围。
原 NumPy Laguerre 求积构造在 192 阶发生上溢并产生 NaN，已改用
`scipy.special.roots_laguerre`，并增加 224 阶有限性、归一化和一阶矩检查。

为避免在各速度节点重复计算同一空间 FFT，新增 `--method separable`。
这只利用当前制造解的结构，不是对任意分布函数作低秩近似。
在每个 μ 节点，g=H1(v,μ)G1(x)+H2(v,μ)G2(x)。全局数值电势仍先由
所有离散速度节点计算。在这个已确定的电势下，RHS 可精确分解为

\[
-vH_1\partial_zG_1-vH_2\partial_zG_2-v\partial_z\psi
-H_1\{\psi,G_1\}-H_2\{\psi,G_2\}.
\]

生产 RHS 内核计算所需空间响应；误差对速度的依赖只有
(H1,H2,vH1,vH2,v) 五项。把各物理速度节点的加权系数矩阵做小型 QR，
再将 R 作用到五个空间误差系数，可得到与逐速度节点求和等价的非负误差范数。
这避免显式 Gram 矩阵在微小误差下的相消。非线性电势响应和括号项均保留。

同时将解析参考中仅依赖 (x,z) 或 (y,z) 的数组保留为二维广播形式，
避免构造不必要的 32×N³ 三维谐波临时数组。
`--method direct --v-block 4` 仍提供完整速度节点的分块计算路径。
新旧路径已在两个空间分辨率上核对投影、方程残差、电势误差；
相关测试共 12 项通过，包含不整除块大小的尾块检查。

**这里的耗时和内存仅代表可分离 MMS 的等价半离散算子验证，
不能当作任意五维分布的存储或时间推进性能。** 完整空间 Fourier 模和速度积分
规则均保持不变，但程序不存放 N³×N_v×N_mu 的通用分布数组。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=jax/src \
  python examples/pde/validate_slab_mms_large.py \
  --sizes 17 33 49 65 81 97 113 129 --n-v 40 --n-mu 192 \
  --method separable --out build/gyrokinetic_mms/spatial129
```

输出 `build/gyrokinetic_mms/spatial129/spatial_convergence.json` 与
`spatial_convergence.png`。每个分辨率仍在独立进程测量资源消耗。
