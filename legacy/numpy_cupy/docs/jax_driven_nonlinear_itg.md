# ITG 驱动、带状流与非线性阶段

在[无驱动守恒模型](jax_nonlinear_itg_conservation.md)上打开固定背景梯度驱动，保留自洽带状流。本次目标是观察从小扰动线性增长转入非线性耦合；没有加入碰撞、人工耗散、外加带状流或饱和幅度限制。

## 实现

`plan_nonlinear_itg(a_n=0., a_t=4.)` 设置密度/温度梯度。默认仍为零，原无驱动测试保持原义。`include_linear=False` 会同时关闭平行运动、磁漂移和梯度驱动，仅留下非线性项。

沿用既有互补扰动 X=√w g，新增

$$R_* = i\rho k_y\left[a_n+a_T(v^2/2+\mu-3/2)\right]\sqrt w\,J\phi.$$

φ 来自当前状态的自洽场求解；驱动不读取预设增长率或参考解。带状闭合仍为 D=1−Γ+τ(1−P₀₀)，P₀₀ 只选中 ky=kz=0。带状模态没有直接梯度驱动，初始值为舍入零，通过 E×B 耦合生成。

`nonlinear_itg_drive_power` 输出密度和温度梯度功率：

$$P_n+P_T=\frac{\operatorname{Re}\langle\widehat X+\sqrt w J\widehat\phi,R_*\rangle}{N_yN_z},\qquad
\dot W=P_n+P_T.$$

`integrate_driven_itg` 在 RK4 的相同四个阶段推进状态与累计驱动功。检验 W(t)−W(0)−∫Pdt，不事后修补能量。非线性括号及标准 BSPF 离散保持不变。

## 算例和观测

有限径向区间 [0,12]，Nx=33，全部31个径向自由度；Ny=9、Nz=7，严格2/3截断后每个周期方向保留0、±1、±2；Nv=12、Nμ=8。ρ=τ=1，κ=0.2，ky,min=0.3，kz,min=0.1，a_n=0、a_T=4。使用原来的三组径向/周期混合扰动，初始幅度降到0.05，推进到 t=40。

关闭非线性的对照组使用完全相同的初值、场闭合、驱动和离散。对照中的 `nl_ratio` 仅表示在其状态上评估的潜在非线性项大小，该项并未参与对照的推进。

Δt=0.05 的结果：

| 诊断 | 含非线性与带状流 | 线性对照 |
|---|---:|---:|
| t=5–15 场能拟合的振幅增长率 |0.1550497|0.1550621|
| t=40 场能 |51.1086|112.8191|
| t=40 带状场能占比 |32.200%|约1e−32|
| 最大驱动功收支残差 / 最大 W |6.80e−9|2.20e−9|

非线性/线性 RHS 范数比在 t≈27 首次达到0.1，t=40 达到0.824。这个0.1是诊断阈值，不是严格的物理分界。后期场能降到线性对照的45.3%，瞬时增长率明显下降，同时带状流与新的径向模态出现。可以据此判断进入非线性阶段；仅凭该对照不能把全部增长抑制单独归因于带状流，其他模态耦合也参与。

时间步减半到0.025后，最终场能为51.10861557，带状场能占比32.199947%，与原步长结果一致；非线性驱动功收支残差降到4.00e−10，线性对照为1.37e−10。早期增长率拟合仍为0.1550497。19项非线性/线性测试通过，包括驱动功瞬时恒等式、驱动单谐波退化检验，以及同阶段累计功预算收敛。

图中带状速度由 v_Ey=−ρ∂x〈φ〉yz 计算，径向导数仍使用 BSPF 求积算子。场能谱按极化权重 D|φ|²/2 积分，分别展示 ky 与径向模态分布。

## 复现与边界

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=jax/src python examples/pde/driven_nonlinear_itg.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=jax/src python examples/pde/driven_nonlinear_itg.py --dt .025 --out build/driven_nonlinear_itg/refined
```

输出包含增长/带状流/收支图 `growth.png/pdf`、模态谱 `spectra.png`、JSON 报告，以及保存电势、诊断、驱动功和最终状态的 `nonlinear.npz`、`linear.npz`。

这是固定梯度、常曲率、无磁剪切模型的早期非线性演化。当前周期/速度网格较小，尚未证明非线性空间和速度收敛；早期拟合数值不是连续速度色散关系的精确增长率。固定背景一直供能，系统无物理耗散，不能把短时增长减缓称为统计稳态饱和。全局剖面反馈、粒子收支、真实几何和雪崩仍在后续范围。
